# Zven 写作桌：本地交互预览

这是概念线框的可操作版本，独立于仓库原有 Expo 工程。使用原生 HTML、CSS、JavaScript 与 Node.js 内置模块，无第三方运行依赖。

**全部种子内容均为虚构示例，不是 Zven 的档案实录。** 输入、归维确认、落盘及修订保存在当前浏览器的本地存储中；数据不上传。不同浏览器、端口或隐私窗口的数据互不共享，清除浏览器站点数据会丢失本地改动。

归维是本地规则生成的提议，不是真实 AI。公开预览只演示过滤后的读法，不提供真实鉴权、发布或安全隔离；静态客户端本身包含示例数据。不要把敏感实录放进这个演示。

## 运行与构建

要求 Node.js 22 或更新版本。进入本目录后，无需安装依赖：

```sh
npm run dev
```

在浏览器打开 `http://127.0.0.1:4318`。服务只监听本机；用 `Ctrl+C` 停止。默认端口被占用时可用 `PORT=4319 npm run dev`，端口值仅接受 1–65535 的整数。页面使用 hash 导航，不需要服务端路由回退。

```sh
npm test
npm run build
```

测试覆盖模型行为，以及草稿保全、确认表单恢复、受限情境信息和锚点范围等界面回归；构建将 `index.html`、`app.mjs`、`model.mjs`、`styles.css`、`favicon.svg` 复制到 `dist/`。重复构建只覆盖这五个输出文件，不删除文件；发现其他文件会停止并保留现场。构建不会发布。预览服务仅提供这五个静态文件，不提供测试、说明、目录列表或其他源码。

## 八条手工走读

1. 从入口进入整卷，确认六个内容维是主要阅读入口；双轨只在写作处作为可选姿势。
2. 在写作桌输入碎片，刷新页面，确认未落盘内容仍在、尚未进入档案。
3. 进入归维确认，修改或拒绝提议，确认操作不会自动落盘；Margo 收起后仍能完成确认。
4. 确认一条新记录，打开其 Node 地址；从不同维度回到该记录，核对仍是同一个地址。
5. 将新内容并入既有 Node，核对地址保持不变、修订史保留旧版。
6. 把暂无内容维的记录送入待归维，再用它继续书写；本版另建记录并保留队列原件，不替未定的待归维身份政策作裁定，队列不要求清空。
7. 组合维度条件、进入 Scenario 与锚点三态，确认筛选范围、空态和回到 Node 的路径。
8. 切换公开阅读预览并直接访问受限记录，确认不显露不可达正文；缩窄窗口检查导航、滚动及表单。

以上是验收操作清单，不表示每一步已完成测试；实际验证结果见本次交付说明。
