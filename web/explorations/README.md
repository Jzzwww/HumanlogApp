# Zven：三种观看方式

2026-09-28 的视觉发散。Zven 对第一版的反馈是：过于琐碎，布局常规、信息杂乱，基调不对，不够科幻与前卫，缺少作品感。

本轮先比较观看体验，不扩充功能。已有交互版保留；这里以独立概念页探索入口、维度选择和一条记录的阅读。方向名只用于方案比较，不是站名、助手名或档案分类。

## 三个方向

- **01 暗场**：用低照度、空间尺度和缓慢运动建立距离。六维是进入观看的方向，正文在选择后出现。
- **02 白场**：以冷白中的异物为视觉中心，用留白和精确排版形成陌生感。维度是观看同一份档案的截面。
- **03 字场**：让巨幅字形与切片本身成为空间。更强烈的颜色和排版承担表达，内容逐步进入。

共同约束：一个样本、一卷档案；六维组织内容；双轨不进入主骨架；不增加监测指标、世界观能力或声音；不代定命名、可见性或其他开放政策。抽象形体是视觉表达，不表示真实档案关系或测量数据。

展开的示例记录沿用同一段虚构文本，以减少内容差异对视觉判断的干扰。当前不是完整档案浏览器，不保存输入，不访问既有预览的 localStorage，不发布实际资料。

## 本地查看

在仓库根目录运行：

```sh
node web/explorations/server.mjs
```

打开 `http://127.0.0.1:4320`。顶栏切换三个完整视口的方案；各方向支持维度选择与记录阅读。方向说明默认折叠。

服务仅绑定本机，显式提供四个 HTML 文件。页面为零依赖、自包含 HTML，使用 CSS、SVG 或 Canvas；无需安装依赖。现有交互版仍在 `web/`，原服务端口 4318。

## 本轮判断问题

先看整体基调是否成立：进入的第一眼是否有一个明确焦点；内容收起后是否仍像一件作品；开始阅读后是否还能感到同一种气质。再看阅读入口能否被发现。视觉方向通过后，再将它延展到实际档案与写作流程。

这里的工程完成仅表示方案可比较，不代表 Zven 已认可视觉方向。

## 本轮核验

四页内联脚本语法与本机服务响应已检查。真实浏览器已核对三方案在 1440px 桌面、390px 手机的首页和阅读态，执行鼠标及键盘进入阅读、退出、方案切换；字场执行下一维度，暗场执行 Escape 关闭。白场额外检查 390×667 矮屏阅读，并修复展开焦点导入与关闭回焦。独立只读复核未发现新增内容政策越界；减少动态偏好的处理经过代码检查，未声称已在系统级切换该偏好实测。
