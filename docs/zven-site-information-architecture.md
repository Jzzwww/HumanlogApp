# Zven 站点信息架构

> 文档性质：概念层信息架构。只回答一件事：已经存在的桌面对象，落在站点的哪里。
> 不含线框，不含界面零件，不含应用代码。版式、色彩、控件留给日后的线框。
> 上游：母文档 `docs/zven-lifecycle-dossier-philosophy-worldview-outline.md` **v0.1.2**；分镜 `docs/zven-interactive-writing-storyboard.md` **v0.1.1**；用法 `docs/zven-writing-desk-usage.md`。
> 版本：IA v0.1。母文档标「待拍板」或「推荐未锁」的，本页不升格。

---

## 0. 这一页管什么

站点要安放的，是写作桌上已经有的东西：两条过程轨、三种档案声音、三个档案单位、可见性、三态同桌。

样本页 `docs/samples/zven-sample-scenario-node-001.md` 仍是格式演示，不是站点上的一页（用法 §7）。

Human 是同一个人。站点按他此刻戴的帽子分地址，不按三个用户分账户（分镜 §1.1，用法 §1）。

---

## 1. 两块过程面，两条轨

写作桌在站点上是一块地方，里面有两块过程面。下笔前的分岔仍是那一句：「要留档还是要被听懂？」（用法 §1，分镜 §4.5）。

| 过程面 | 轨 | 谁在写 | 旁边的助手 | 落在站点的哪里 |
| --- | --- | --- | --- | --- |
| 留档 | 观察者轨 | 观察者。第三人称写 Zven | Margo · 玛戈。只对观察者 | 可成为档案正文，以及正文之外的可折叠边栏 |
| 被听懂 | Zven 轨 | Zven 这一侧。第一人称 | 另一位助手。暂名「陪写」/ Companion-desk，**暂名未锁** | Zven 层或私聊。不进观察者正文，不占边栏 |

陪写不是 Margo，也不替换 Margo（用法 §1，分镜 §4.5）。

**档案成品仍是三种声音**，不因双轨多出第四个说话区（分镜 §1.2、§8.1）：

| 声音 | 说话者 | 在站点上的位置 |
| --- | --- | --- |
| 正文声 | 观察者 / Observer | 一条档案的主体。不可折叠 |
| 摘录声 | 样本 | 嵌在正文里的「样本自述摘录」。必带时间、证据等级、摘录标记（母文档 §2.2.2） |
| 边注声 | Margo | 正文之外的可折叠边栏。折上之后正文仍然完整（母文档 §3.1，用法 §2） |

陪写的话只活在 Zven 层或私聊。它没有档案地址（用法 §2 第 4 条，分镜 §4.5、§8.1）。

过程里两轨可以来回，角色可以模糊。换面不等于落盘。落入档案时格式收回：正文第三人称；第一人称只在摘录；Margo 不对 Zven 说话；陪写不跟进去（用法 §2，分镜 §4.5）。

把 Zven 笔记留进档案，是一次明确的提升，不是导航的副作用：正文改回第三人称，要留的原话放进摘录，陪写的话留在原处（用法 §6，分镜 §4.5）。不提升也可以结束。

## 2. 三个单位

整站只有一个样本、一卷档案。站内不出现其他样本或其他观察者（母文档 §2.1、§2.5）。

| 单位 | 站点上是什么 | 地址 |
| --- | --- | --- |
| Dossier | 这一卷的当前版本。没有完成态（母文档 §2.5） | 整卷一个位置。工作标题用《Zven 卷》，标注推荐未锁（母文档 §4.2） |
| Scenario | 一块可以互相解释的场。不是章节，不是时间段。彼此可以重叠（母文档 §2.5） | 卷内可被定位的一块。一条档案可以先不属于任何一块 |
| Node | 最小记录。一次落笔 | **持久地址**。可引用、可链接、可交接（母文档 §3.4，分镜 §8.2） |

Node 在地址上带着这些字段（母文档 §2.5；可见性见母文档 §4.5）：

- 时态：溯源／现场／假说
- 事件时间
- 档案时间
- 证据等级
- 修订史
- 可见性

假说态另带回访条件。回访结果是新的 Node、新的地址，关联原假说；原地址上的假说不改（母文档 §2.3.6）。

可选、且不因此另开一种单位：所属 Scenario、主题锚点、关联 Node。一个 Node 能否同时属于多块 Scenario，仍待拍板；站点先允许「属于一处，或暂时哪里都不属于」（母文档 §4.7，分镜 §3）。

修订史是这条地址上的内容，不是侧边的管理备注（母文档 §2.3.5）。粒度不在本页锁定。

缺口是被标记的空白，落在桌上或 Margo 边栏里，不是第六种单位（母文档 §2.5，沉默律 §2.4 第 6 条）。

认知 × AI 时代索引若被用到，只是打在 Node 上的标记，不是单独的站点栏目（母文档 §2.5）。维度集合不在本页锁定。

这里不另设一种叫「草稿」的档案单位（分镜 §4.4）。未发布的 Node 仍是 Node，只是可见性停在保守默认。

## 3. 默认保守

新 Node 写完，进入档案的当前版本，不对外（母文档 §3.3、§4.5，分镜 §6，用法 §5）。

- 可见性是 Node 上的字段。公开哪一条，由作者选择。
- Scenario 可以另有一层可见性。未单独设定的，保持保守默认。
- 两层如何互相覆盖，留给线框。本页不另造覆盖规则（分镜 §6）。
- 公开出去的仍是当前版本，不是定论。读者的反应不构成修订理由（母文档 §3.3）。
- 抹除只在两种情形：第三人隐私，或样本明确撤回。地址上留下「此处曾有一条记录被撤回」（母文档 §2.4 第 3 条）。

双语不是另一个地方。摘录可以在同一条 Node 地址上保留原语言（母文档 §4.9，用法 §5）。

---

## 4. 三态同桌可见

过去（溯源）、现在（现场）、未来（假说）要在同一张桌上被一起看见。这是站点要求，不是版式决定（母文档 §2.3.2，分镜 §2.1、§8.2）。

字面的三栏留给日后线框。本页只要求：读者停在一块场或一条锚点上时，三态的有无都能同时被读到。空着的一态是缺口，不是待填的槽，也不是已取消的元素 6（分镜 §2.1、§8.1）。

主题锚点是把三态拉到同一行的依据。锚点未齐时，行可以标成尚未成立。单条 Node 可以先没有锚点（母文档 §2.3.2，分镜 §2.1）。初始集合不在本页锁定（母文档 §4.7）。

两条时间在 Node 地址上同时可见。它们的距离是信息，不是两个页面（母文档 §2.3.3）。

## 5. 站点地图（概念）

下面是位置，不是界面。不规定页眉、按钮、分栏宽度，也不规定路径字符串。

```
入口
 └─ 写作桌（双轨）
     ├─ 观察者过程面 …… 可提升为档案
     └─ Zven 过程面 ……… 留在 Zven 层或私聊
档案（一卷 Dossier，当前版本）
 ├─ 浏览整卷
 ├─ 一块 Scenario
 └─ 一条 Node 的持久地址
     ├─ 观察者正文
     ├─ 样本自述摘录（可无）
     └─ Margo 边栏（可折叠）
可见性／发布 …… 写在 Node 上；Scenario 可选。不是必经的一页
公开子集 ……… 可选。只含作者选出的地址
```

| 位置 | 放什么 | 不放什么 |
| --- | --- | --- |
| 入口 | 作品身份。标题、样本称呼、定位语若出现，带着「推荐未锁」（母文档 §4.2，分镜 §0） | 引导教程、对样本的欢迎词、第六槽（分镜 §7） |
| 写作桌 | 两块过程面的分岔 | 档案成品本身 |
| 观察者过程面 | 正文起草，以及 Margo 的缺口、证据、回访、时间对齐 | 陪写的对话 |
| Zven 过程面 | 第一人称笔记，以及陪写 | 观察者正文；Margo 边栏 |
| 整卷浏览 | 这一份 Dossier 的当前版本。Scenario 与 Node 从这里被找到 | 第二卷、其他样本 |
| Scenario | 一块场，以及它目前所含的 Node | 生命阶段关卡 |
| Node 持久地址 | 一条记录的三种声音、两轴时间、证据、修订史、可见性 | 陪写全文 |
| 可见性／发布 | 作者对 Node（及可选 Scenario）的选择。附着在记录上 | 第四种声音；已定的「仅交接人可见」层 |
| 公开子集 | 已选出的 Node（及其摘录与可折叠边栏） | Zven 层、私聊、未公开的 Node |

持久优先于催促。站点没有推送、没有打卡、没有连续签到（母文档 §3.4，分镜 §8.2）。

观察站是位置的通名，不是必须被画成一页的文明史。物理形态留空。站名未定，地图上用「观察站」即可，不单开一页（母文档 §2.1，分镜 §8.1）。

## 6. 导航与地址

Human 在轨与档案之间移动时，角色纪律跟着地址走。本页不规定 URL 写法。持久指的是：一条 Node 被引用之后，地址还在。

1. **进桌先选轨。** 从入口到写作桌，下一跳是两块过程面之一。一场里可以换面（用法 §6，分镜 §4.5）。换面只换过程面，不把对面的助手带过来。
2. **过程面不占用 Node 的持久地址。** Zven 层或私聊不被公开子集收录。观察者过程面上尚未落盘的句子，同样还不是一条 Node。
3. **进入档案要经过落盘。** 观察者轨的成品直接成为正文与边栏。Zven 轨只有在作者做了提升之后，才在 Node 地址上出现；提升不搬运陪写（用法 §2、§6）。
4. **读档案不打开第四个说话区。** 从整卷、从一块 Scenario、或从一条 Node 的持久地址进来，读者看到的都是三种声音。边栏可折。折上之后这条地址仍然完整（分镜 §8.1）。
5. **从档案回到过程面，私聊不写进已落盘的 Node。** 回到观察者过程面，是继续以观察者修订或另写。回到 Zven 过程面，是另一次被听懂。修订是一次新的观看，旧版留在同一条地址的修订史上（母文档 §2.3.5）。
6. **公开与私密在地址上分开。** 具体机制未定（母文档 §3.4，分镜 §8.2）。要求只有：未公开的地址到不了公开子集；公开子集里的一条，仍是那条 Node 的当前版本。
7. **不认识样本的读者只走公开子集。** 交接律要求写法可被此人读懂（母文档 §2.4 第 7 条）。他不进入写作桌的 Zven 过程面。是否另有「仅交接人可见」的地址层，本页不设（母文档 §4.5 仍开放，分镜 §8.3）。

任意一条已落盘的 Node 都可以被直接打开，不要求从入口按时间读起（母文档 §3.1）。

## 7. 本页不锁定

下列事项保持上游的状态。信息架构不补决定，也不为它们预留已定的页面。

| 事项 | 状态 | 依据 |
| --- | --- | --- |
| 证据等级的档数、命名、摘录如何定级 | 未锁。示意档只说明字段存在 | 母文档 §2.5、§4.3；分镜 §3.1 |
| 主题锚点的初始集合 | 未锁 | 母文档 §4.7 |
| 修订史粒度 | 未锁 | 母文档 §2.3.5、§4.7 |
| 观察站专名 | 仍开放。通名用「观察站」 | 母文档 §4.2；分镜 §8.1 |
| 「仅交接人可见」层 | 仍开放。不预做地址 | 母文档 §4.5；分镜 §6、§8.3 |
| 对外标题、样本称呼、定位语 | **推荐未锁** | 母文档 §4.2 |
| 元素 6 | **已取消。** 站点不留第六槽 | 母文档 §0.2 第 6 条、§4.1 |
| 观察者专名 | **无专名。** 称「观察者」/ Observer | 母文档 §4.2 |
| Gnomon／晷针、Tally／塔利，以及其余未选用的观察方与助手候选 | **不得**用作站名、观察者名、助手名或栏名 | 分镜附录；命名草案 §1、§2 |

陪写／Companion-desk 是 Zven 轨助手的暂名，不是本页新锁的产品名（分镜 §4.5，用法 §1）。

一个 Node 能否属于多块 Scenario、时代索引的维度、第三人能否请求撤回、生命周期两端与交接人机制，仍以母文档 §4.4、§4.6、§4.7 为准。本页不把它们写成站点栏目。
