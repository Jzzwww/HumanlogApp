## 0. 这一页管什么

站点要安放的，是这一卷在积攒与组装时用到的东西（维度 §0）：

- 一个**输入层**。碎片进来的地方，不设限（维度 §2.1）。
- 一个**待归维队列**。过了门、暂无内容维落点的记录（维度 §5）。
- 三个**档案单位**。Dossier／Scenario／Node（母文档 §2.5）。
- 打在 Node 上的**维度标记**。六个内容维、四个结构维（维度 §3）。不是新单位。
- 两块**过程面**。观察者过程面、Zven 过程面。它们是书写姿势，不是骨架（维度 §1.3）。
- **三种声音**。正文声、摘录声、边注声（母文档 §2.2.2）。
- 若干**读法视图**。按维拉出、多维交集、锚点 × 三态行等（维度 §4.3）。不是新单位。
- 一个**公开子集**。同一套 Node 地址按可见性过滤后，外部读者能到达的部分（本页 §3.2）。
- 一个通名：**观察站**。

v0.1 把站点骨架搭在「两条轨」上。v0.2 改按维度文档：**骨架是维度，轨是姿势。** 双轨表述在本页如何降级，见 §1.3。

样本页 `docs/samples/zven-sample-scenario-node-001.md` 仍是格式演示，不是站点上的一页（用法 §7）。

Human 是同一个人。站点按他此刻戴的帽子分地址，不按三个用户分账户（分镜 §1.1，用法 §1）。

用词两注：用法页的「侧栏」即本页的「边栏」。本页的「入口」指站点门面；母文档 §3.1 的「任意入口」指任一 Node 可被直接打开。两者不是一回事，本页在后一义上一律写「直接打开」。

## 1. 主流程与过程面

### 1.1 主流程

站点上的一次书写走维度 §4.1 的五步。每一步落在哪里：

```
输入（不限）           …… 输入层。不落盘，无地址
  → 归维提议            …… 系统在输入层给出。样本侧无声
  → Human 确认／改／拒   …… 观察者过程面。提议需要解释时，以 Margo 边注对观察者出现
  → 落盘                …… 新 Node（持久地址）；或并入既有 Node（修订／摘录）；或移入待归维队列
  → 组装读法            …… 档案内的视图：按维、按场、按锚点。不生新单位，不改地址
```

四条位置性的规定：

1. **输入不落盘。** 输入层里的东西没有持久地址（§1.4）。
2. **确认归维落在观察者过程面。** 这是本页推导，不是上游原文：确认归维是书写权动作（母文档 §2.2.4）；维度 §4.2 规定提议的解释只以 Margo 边注对观察者出现；能承接这两点的位置只有观察者一侧。Human 以 Zven 姿势写下的碎片，也在这里确认。
3. **落盘是进入档案的唯一通道。** 观察者姿势写的、Zven 姿势写的，都走它（维度 §7.2）。用法 §6 的「提升」在本页就是这一步：改回第三人称或放进摘录，补齐时态、两轴时间、证据档，确认维度，得到地址。
4. **组装不生新单位、不改地址**（维度 §4.3）。视图的位置见 §4、§5。

### 1.2 两块过程面是姿势

写作桌在站点上是一块地方：输入层，加上归维确认。坐下时可以选一个姿势（用法 §1，分镜 §4.5），也可以不选，直接把碎片丢进输入层（维度 §7.2）。

| 过程面 | 姿势 | 旁边的助手 | 与输入层的关系 | 落在站点的哪里 |
| --- | --- | --- | --- | --- |
| 观察者过程面 | 观察者。第三人称写 Zven | Margo · 玛戈。只对观察者 | 输入；**并承接归维确认**（§1.1 第 2 条） | 写作桌内。这里确认过的碎片成为 Node |
| Zven 过程面 | Zven 这一侧。第一人称 | 另一位助手。暂名「陪写」/ Companion-desk，**暂名未锁** | 只输入。第一人称碎片进同一个输入层 | 写作桌内。v0.1 所说的「Zven 层」在本页＝输入层上以 Zven 姿势写下的那部分 |

陪写不是 Margo，也不替换 Margo。它不参与归维、不打标记、不进 Dossier、不进边栏（维度 §7.4）。它的话不是碎片。

过程里两面可以来回，角色可以模糊。换面不等于落盘（用法 §2）。换面只换过程面，不把对面的助手带过来。

### 1.3 对 v0.1 双轨表述的降级

| v0.1 表述 | v0.2 改为 | 依据 |
| --- | --- | --- |
| 「下笔前的分岔仍是那一句：要留档还是要被听懂」 | 可问可不问。第一问是收录与归维；人称是落盘时的声音层取值 | 维度 §1.1、§7.1 |
| 「进桌先选轨」（v0.1 §6 第 1 条） | 进桌先到输入层。选姿势是可选的一跳 | 维度 §7.2 |
| 写作桌＝「两块过程面的分岔」 | 写作桌＝输入层＋归维确认。过程面是它的两种姿势 | 维度 §1.3 |
| 「观察者轨的成品直接成为正文与边栏」 | 观察者姿势的碎片同样经归维确认再落盘，不绕过收录标准 | 维度 §2.1、§4.1 |
| 「Zven 轨只有在作者做了提升之后才在 Node 地址上出现」 | 结论保留。「提升」是归维与落盘的别名，不是另一条通道 | 维度 §7.2 |
| 「陪写的话只活在 Zven 层或私聊」 | 结论保留。补：站点是否持存它、「私聊」是否站外，见 §1.4 与 §7 | 用法 §2 第 4 条 |

不降级的是落盘格式：正文第三人称；第一人称只在摘录；Margo 不对 Zven 说话；陪写不跟进去（用法 §2，分镜 §4.5）。

### 1.4 未落盘内容的持存（工作默认／推荐未锁）

| 内容 | 工作默认 |
| --- | --- |
| 输入层碎片：观察者半成品、Zven 姿势的第一人称笔记、三项不齐暂不入未来层的句子（分镜 §4.4） | **站内、非地址。** 站点持存它，跨场仍在。没有持久地址，不进公开子集，不进任何视图。它不是缺口（维度 §2.1「未收录」） |
| 未确认的归维提议 | 站内、非地址。附着于它的碎片。未确认不落盘（维度 §4.1 第 4 条） |
| 陪写的话 | **不进输入层，不进公开子集，不进边栏。** 站内持存还是站外「私聊」，**未定**，列 §7。若站内，同样非地址 |
| 待归维队列 | 不属于本表。它已过门，见 §2.4 |

「站内非地址」只有一个含义：这里的东西没有母文档 §3.4 的持久地址，不能被引用、链接、交接。本页不发明它的界面。

### 1.5 三种声音

档案成品仍是三种声音，不因双轨、归维或视图多出第四个说话区（分镜 §1.2、§8.1；维度 §6.2）：

| 声音 | 说话者 | 在站点上的位置 |
| --- | --- | --- |
| 正文声 | 观察者 / Observer | 一条 Node 的主体。不可折叠 |
| 摘录声 | 样本 | 嵌在正文里的「样本自述摘录」。必带时间、证据档、摘录标记（母文档 §2.2.2） |
| 边注声 | Margo | 正文之外的可折叠边栏。折上之后正文仍然完整（母文档 §3.1，用法 §2） |

Margo 边栏出现在两处：观察者过程面（缺口、证据、回访、时间对齐，外加归维解释，维度 §7.3）与 Node 持久地址上。到期的回访提醒只在这两处的边栏出现，不出站、不推送（母文档 §2.3.6、§3.4）。

归维提议、待归维汇总、组装视图都不是第四种声音。陪写的话没有档案地址。

## 2. 三个单位、维度标记、队列

整站只有一个样本、一卷档案。站内不出现其他样本或其他观察者（母文档 §2.1、§2.5）。

### 2.1 单位

| 单位 | 站点上是什么 | 地址 |
| --- | --- | --- |
| Dossier | 这一卷的当前版本。没有完成态（母文档 §2.5）。整个上下文库就是这一卷（维度 §6.1） | 整卷一个位置。工作标题用《Zven 卷》，标注推荐未锁（母文档 §4.2） |
| Scenario | 一块可以互相解释的场。不是章节，不是时间段。彼此可以重叠（母文档 §2.5）。维度相同不自动成场；成场由 Human 决定，系统只提议（维度 §6.1） | 卷内可被定位的一块。一条 Node 可以先不属于任何一块 |
| Node | 最小记录。一次落笔。碎片收录后的形态（维度 §6.1） | **持久地址**。可引用、可链接、可交接（母文档 §3.4，分镜 §8.2）。**地址不以 Scenario 为前缀**：Node 是否多属 Scenario 仍待拍板（母文档 §4.7），地址方案不排除多属 |

Node 在地址上带着（母文档 §2.5；可见性见母文档 §4.5）：时态、事件时间、档案时间、证据档、修订史、可见性；假说态另带回访条件。回访结果是新的 Node、新的地址，关联原假说；原地址上的假说不改（母文档 §2.3.6）。

可选、且不因此另开一种单位：所属 Scenario、主题锚点、关联 Node。一个 Node 能否同时属于多块 Scenario，仍待拍板；站点先允许「属于一处，或暂时哪里都不属于」（母文档 §4.7，分镜 §3）。

修订史是这条地址上的内容，不是侧边的管理备注（母文档 §2.3.5）。粒度不在本页锁定。「当前版本」指 Dossier 没有完成态，不指隐藏旧版：旧版留在同一条地址的修订史上可查。

这里不另设一种叫「草稿」的档案单位（分镜 §4.4）。未发布的 Node 仍是 Node，只是可见性停在保守默认。

### 2.2 维度标记不是单位

维度文档 §3 的六个内容维（认知判断、作品项目、技艺方法、关系接触面（代号）、时代索引、意义取向）与四个结构维（时间态、证据档、声音层、可见性），在站点上都是**打在 Node 持久地址上的标记**。同一条碎片只有一个地址，多维标记都打在这一个地址上（维度 §3.4 第 4 条）。

- 结构维中的四条就是 Node 必带字段或已锁属性，不是新东西（维度 §3.1）。
- 标记有修订史。改一次标记是一次新的观看（维度 §3.4 第 5 条），留在同一条地址上。
- **认知 × AI 时代索引**是六个内容维之一（维度 §3.2）。它的「横向检索」（母文档 §2.5）在站点上就是按这一维拉出的视图（§5.2），不是单独的栏目。维度集合待拍板。
- 代号表与项目代号表由 Human 维护（维度 §3.2）。在站点上它们是标记的取值来源，不是档案单位，本身不进公开子集；公开的只是打在公开 Node 上的那个代号（**工作默认／推荐未锁**）。位置不在本页锁定。

### 2.3 缺口的载体（工作默认／推荐未锁）

缺口是被标记的空白（母文档 §2.5，沉默律）。它不是另一种单位。评审 2-G 问它挂在哪、折上边栏还在不在、随不随公开。本页给工作默认：

| 缺口在标记什么 | 载体 | 折上边栏后 | 可见性 |
| --- | --- | --- | --- |
| 一条 Node 内的空白：事件时间缺失、来源不明、判断未决 | 该 Node | **仍可见。** 缺口标记与时态、证据档同属地址上的结构标记，不属于边注声 | 随该 Node |
| 一块场或整卷里的时段空白：几个月无 Node | 该 Scenario，或整卷 | 仍可见 | 随该 Scenario；整卷级的缺口默认不对外 |
| 一条锚点行里某一态无内容 | 该锚点行（§4） | 仍可见 | 见 §3.3：公开子集内锚点行的空格如何标，待拍板 |

Margo 边栏里的缺口清单是对这些标记的**解释与汇总**，不是标记本身的唯一住处。母文档 §2.5 缺口的三种去向（被填补、确认为永久空白、保留为待回访）是标记上的状态，状态改变留痕。

### 2.4 待归维队列

维度 §5 的队列在站点上是一个**位置**，不是单位，也不是元素 6 的替身。

- 队列里的每条已过收录门、带全部结构维、按维度 §5.2 有地址，可被引用；缺的只是内容维。它不进任何按内容维组装的视图。
- 队列不对外。可见性停在默认，不进公开子集。不设上限，不设清空期限，不显示「待处理数」（维度 §4.2、§5.2）。
- 「待归维里的记录是否即一条 Node」：维度 §2.1（收录成 Node 须至少落一个内容维）与 §5.2（队列记录已有地址）措辞有出入。本页按 §5.2 给它地址、按 §5.2 不让它进视图，其余列 §7 待拍板。

### 2.5 不另设的单位

草稿、视图、锚点行、公开子集、队列、维度标记、缺口，都不是单位。单位只有三个。

## 3. 默认保守与公开子集

### 3.1 可见性

新 Node 写完，进入档案的当前版本，不对外（母文档 §3.3、§4.5，分镜 §6，用法 §5）。

- 可见性是 Node 上的字段。公开哪一条，由 Human 逐条选。系统只能给默认值，不能提议公开（维度 §3.2、§6.3）。
- Scenario 可以另有一层可见性。未单独设定的，保持保守默认。
- **两层覆盖方向（工作默认／推荐未锁）：更严者生效。** 任一层更保守，则以更保守的一层为准。这是政策不是版式，v0.1 的「留给线框」撤回；终锁列 §7。
- 视图的可见性等于其中每条 Node 各自的可见性，不因被组装在一起而升格（维度 §6.3）。
- 公开出去的仍是当前版本，不是定论。读者的反应不构成修订理由（母文档 §3.3）。
- 抹除只在两种情形：第三人隐私，或样本明确撤回。地址上留下「此处曾有一条记录被撤回」（母文档 §2.4 第 3 条）。这个标记在公开子集里是否可见，列 §7。

双语不是另一个地方。摘录可以在同一条 Node 地址上保留原语言（母文档 §4.9，用法 §5）。

### 3.2 公开子集是什么

**公开子集不是第二套地址。** 它是同一套 Node 持久地址按可见性过滤之后，外部读者能到达的部分。一条 Node 从不对外变为公开，地址不变；引用与交接不断（母文档 §3.4、§2.4 第 7 条）。

- 公开子集**可以为空**。它不是「站点可以没有公开面」——作品身份要求有可读面（母文档 §3.1）；只是这个面上的地址数可以是零。
- 公开的一条 Node 带着它的正文、摘录、可折叠边栏一并公开。边栏随 Node 公开是从母文档 §3.1「边注声是作品的一部分」推导，不是上游原文。
- 公开子集里能打开的视图（§5.2）只由公开 Node 组成。整卷浏览、Scenario、锚点行在公开子集里都是过滤后的样子。
- 永远不进公开子集的：输入层、待归维队列、陪写的话、未公开的 Node。

### 3.3 公开子集里的空格（待拍板）

公开子集里一条锚点行的某一态为空，可能是缺口，也可能只是未公开。是否向读者区分这两种空、怎样标，本页不定，列 §7。线框前的工作默认：一律标「此处无公开内容」，不标为缺口。

## 4. 三态同桌：锚点 × 三态行

过去（溯源）、现在（现场）、未来（假说）要在同一张桌上被一起看见。这是站点要求，不是版式决定（母文档 §2.3.2，分镜 §2.1、§8.2）。字面的三栏留给线框。

### 4.1 锚点行是视图

**锚点 × 三态行**在站点上是一种**视图**（维度 §4.3：三态并置是组装的一种，以锚点为行、三态为列）。它不是单位，不是维度，不产生第二套地址；行里每一格是若干 Node 的持久地址，空格是缺口标记或「无公开内容」（§3.3）。

**工作默认／推荐未锁：锚点行独立可达。** 读者可以直接停在一条锚点上（母文档 §2.3.2），不必先经整卷或 Scenario；整卷浏览与 Scenario 内也各有一份锚点行清单（整卷列全部锚点；Scenario 只列该场所含 Node 触及的锚点）。是否给锚点行一个可被引用的稳定位置、其稳定性是否与 Node 地址同级，列 §7；本页只承诺 Node 地址持久。

### 4.2 行的成立与到达

- 主题锚点是把三态拉到同一行的依据。每个锚点至少两个时态有内容才成立；锚点未齐时，行**标成尚未成立**（母文档 §2.3.2，分镜 §7.1 第 6 拍）。单条 Node 可以先没有锚点。初始集合不在本页锁定（母文档 §4.7）。
- **Node → 锚点行**：Node 地址上的锚点标记是一跳，跳到该锚点的三态行；**锚点行 → Node**：行里任一格跳回其中的 Node 地址。双向。
- 维度标记是锚点提议的依据，不替代锚点（维度 §4.3）。锚点不是维度（维度 §3.3）。

两条时间在 Node 地址上同时可见。它们的距离是信息，不是两个页面（母文档 §2.3.3）。

### 5.1 位置树

     │   ├─ 样本自述摘录（可无）
     │   ├─ Margo 边栏（可折叠）

| 待归维队列 | 已过门、暂无内容维的记录 | 「待处理数」；公开 |

| 读法视图 | 同一套 Node 的重排 | 新地址；新单位 |

持久优先于催促。站点没有推送、没有打卡、没有连续签到（母文档 §3.4，分镜 §8.2）。

### 5.2 读法视图清单

两个词的定义：**视图**＝对同一套 Node 的一种组装读法，不是单位，不产生第二套地址；**独立可达**＝能被直接打开，不必先经过整卷或 Scenario。一个视图可以同时是独立可达的。以下可达性均为**工作默认／推荐未锁**。

| 视图 | 组成 | 挂在哪 | 独立可达 | 依据 |
| --- | --- | --- | --- | --- |
| 锚点 × 三态行 | 一个锚点下，三态各为一列，格内是 Node | 整卷浏览；Scenario 内 | 是（§4.1） | 母文档 §2.3.2；维度 §4.3 |
| 按一维拉出 | 某内容维某取值下的全部 Node | 整卷浏览；Scenario 内可再限于场内 | 是 | 维度 §4.3 |
| ├ 项目史 | 按作品项目维某项目代号拉出，即状态词流水 | 同上 | 是（它就是一维视图） | 维度 §3.2 作品项目 |
| ├ 代号史 | 按关系接触面维某代号拉出，即「Zven 与此人的那一面」 | 同上 | 是（同上） | 维度 §3.2 关系接触面 |
| ├ 改判史 | 按认知判断维某一判断拉出 | 同上 | 是（同上） | 维度 §3.2 认知判断 |
| └ 时代索引横向检索 | 按时代索引维某取值拉出 | 同上 | 是（同上）。不是单独栏目 | 母文档 §2.5；维度 §3.2 |
| 多维交集 | 两个或多个维度取值的交集 | 从按维拉出内再收窄 | 可达，但不承诺稳定位置 | 维度 §4.3 |
| 修订史 | 一条地址的历次版本 | Node 地址上 | 随 Node | 母文档 §2.3.5 |

视图的规则（维度 §4.3、§6.3）：组装结果是当前版本；同一组维度在不同时刻组装出的读本可以不同，这个不同是内容；观察者若在组装后另写理解，那是一条新 Node，带推断档；视图的可见性等于其中每条 Node 各自的可见性。

## 6. 导航与地址

Human 在写作桌与档案之间移动时，角色纪律跟着地址走。本页不规定 URL 写法。持久指的是：一条 Node 被引用之后，地址还在。

### 6.1 入口的下一跳

入口是同一处。下一跳按帽子分：

| 谁 | 下一跳 | 到不了 |
| --- | --- | --- |
| Human（作者） | 写作桌，或档案。两条都通 | — |
| 不认识样本的读者 | 档案的公开子集：整卷浏览、Scenario、Node、视图的公开可达部分（母文档 §2.4 第 7 条） | 写作桌（输入层、两块过程面、待归维队列）；未公开的 Node |

是否另有「仅交接人可见」的地址层，本页不设（母文档 §4.5 仍开放，分镜 §8.3）。

### 6.2 写作桌内

1. **进桌先到输入层。** 选姿势是可选的一跳（§1.2、§1.3）。一场里可以换面；换面只换过程面，不把对面的助手带过来。
2. **过程面不占用 Node 的持久地址。** 输入层里的句子还不是一条 Node（§1.4）。
3. **归维确认在观察者过程面。** 确认后落盘：新 Node，或并入既有 Node，或移入待归维（§1.1）。
4. **待归维 ↔ 观察者过程面。** 队列里的记录可被拉回确认；升维经维度 §5.3 的程序，不在站点上另设一步。

### 6.3 档案内的边

母文档已定的概念关系，本页只列存在与方向，不规定控件（评审 2-F）：

| 边 | 方向 | 说明 | 依据 |
| --- | --- | --- | --- |
| Node ↔ 所属 Scenario | 双向 | Node 地址上的 Scenario 标记跳到场；场内列出 Node。Node 可以暂不属于任何一块，则此边为空 | 母文档 §2.5 |
| Node ↔ 锚点行 | 双向 | §4.2 | 母文档 §2.3.2 |
| Node ↔ 维度视图 | 双向 | 地址上任一维度标记跳到该取值的一维视图；视图内跳回 Node | 维度 §4.3 |
| 假说 Node ↔ 回访结果 Node | 双向 | 结果是新 Node，关联原假说；原假说不改。一条假说可被多次回访，则一对多 | 母文档 §2.3.6 |
| Node ↔ 关联 Node | 双向 | 可选字段 | 母文档 §2.5 |
| Node → 修订史各版本 | 单向进入，版本间可来回 | 同一条地址上的内容。旧版可查 | 母文档 §2.3.5 |
| 撤回后的地址 → 「此处曾有一条记录被撤回」 | 地址仍在 | 地址不消失，内容换成标记。指向它的引用不断 | 母文档 §2.4 第 3 条 |
| 缺口标记 → 其载体 | 单向 | 缺口挂在 Node／Scenario／锚点行上（§2.3）；Margo 边栏的缺口清单跳到载体 | 母文档 §2.5 |
| 整卷 → Scenario → Node | 逐级进入 | 也可跳过任一级：任意一条已落盘的 Node 都可以被直接打开，不要求从入口按时间读起（母文档 §3.1） | 母文档 §3.1 |

### 6.4 档案与写作桌之间

1. **读档案不打开第四个说话区。** 从整卷、从一块 Scenario、从一个视图、或从一条 Node 的持久地址进来，读者看到的都是三种声音。边栏可折。折上之后这条地址仍然完整，缺口标记仍在（§2.3）。
2. **从档案回到写作桌，不把已落盘的 Node 带回输入层。** 修订是一次新的观看，旧版留在同一条地址的修订史上（母文档 §2.3.5）。回到 Zven 过程面，是另一次以第一人称输入。
3. **公开与私密在同一套地址上分开。** 要求只有两条：未公开的地址到不了公开子集；公开子集里的一条仍是那条 Node 的当前版本，地址与私密时相同（§3.2）。具体机制未定（母文档 §3.4，分镜 §8.2）。

### 8.4 与双轨的关系
