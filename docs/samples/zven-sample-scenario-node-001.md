## 给 Human 的读法

先分声音，再读事情。

主区是观察者。写 Zven 用第三人称。观察者的「我」只在一处出现，标记停留。引号块内才是样本的第一人称；块外立刻回到第三人称。侧栏是 Margo 对观察者的提议。折上侧栏，正文仍然完整。

「同事甲」「友人·烛」是占位代号。Human 日后指定正式代号。真名不进正文。本页不推测他们的内心。

本 Node 的可见性是 **私密草稿**。这是发布分级上的一档，不是另一种档案单位。分级里可以另有「可公开候选」；本页不取那一档。Scenario 未单独设定可见性，保持保守默认。

证据档用母文档的示意默认：现场／近场／回忆／转述／推断。档数与命名仍未锁。摘录如何定级仍开放；本页暂按摘录与事件的距离来标，并允许日后复核。

文件名中的 `001` 是这份样本稿的序号，不是样本编号。档案里只有这一个样本。

一条 Node 有一个主时态。本页主时态是现在。过去残迹与未来假说写在同一页上，是这一次落笔还没拆开的样子。侧栏记下它们可以怎样另立。这里不另造一种叫「草稿」的档案单位。

### 观察者正文

Zven 在这一晚把一句没有写完的话交给一个模型。句子停在半路。模型把后半句补上。补上的部分是一个完整的谓语。主语仍是他。

他读了两遍。第一遍之后，补上的部分还在。第二遍，他把它删掉。光标回到原来的断口。他没有重写。过了一段没有被计时的空档，他关上这一页。

我在断口处停留。

同周较早的一次交谈里，同事甲说到：没写完的稿子可以交给工具收尾。Zven 在那次交谈里没有接这句话。本页只记接触面。

更早，友人·烛留过一条短讯。Zven 在这一晚打开过它，没有回复。短讯的字句本页不录。

#### 过去 · 残迹

若干季节以前的事，Zven 今夜记得成这样：句子被故意停在半路，为的是第二天从断口接着想。

这条不是那一季的现场。它是今夜如何记得那一季。事件时间只到「某一季」。档案时间与上面的正文同夜。证据等级：**回忆**。

那一季是否逐日留着断口，本页不能升成事实。

#### 未来 · 假说

以下是假说，不是预报，也不是愿望。

- **假说：** 自本 Node 的档案日起九十日内，当 Zven 写下需要他自己做判断的句子、并且句子停在半路时，他仍会先把断句交给模型，并在留下补全之前至少删去一次。
- **回访时间点：** 2026-12-27（档案日加九十日）。
- **不成立：** 到该日为止，此类书写里他有连续三次没有把断句交给模型；或他交出断句之后直接保留补全、不再删去。若期间没有留下此类书写的痕迹，回访结果为**无法判定**。成立、不成立、无法判定三种地位相同。回访写成新的 Node。这一条不改。

### Margo · 侧栏

对观察者。折上之后，上面的正文仍然完整。

- **缺口。** 断口之前的原句没有录入。同事甲那次交谈没有单独的现场 Node，只有本页的接触面。友人·烛的短讯字句未录；空白保持为缺口。某一季没有更近的事件日期。这些空白不拿另一句话填上。
- **证据。** 主段与摘录目前为「近场」。两轴同日，中间有一段未计时的空档；若你确认落笔就在事件当时，可改标「现场」。溯源残迹保持「回忆」，不得写成那一季的日程。摘录后一句保留原文语言；我不译，也不改引号内的字。定级方式仍开放，此档可待复核。
- **时间对齐。** 现场的事件时间与档案时间同在 2026-09-28 夜。溯源的事件时间远于档案时间，这段距离是信息。假说的回访点是 2026-12-27，尚未到来。
- **回访。** 假说三项已齐：内容、回访点、不成立情形。它还写在本 Node 页内。若你要它成为未来态 Node，应另立一条，本条保持不动。到日之后由你书写结果。
- **锚点。** 注意力已有两态，本页可以把它当作成立。人机边界只作索引标记。是否把残迹与假说拆成另外两条 Node，由你决定。忽略本栏是完整的操作。
- **可见性。** 本 Node 为私密草稿。Scenario 没有另设一档。
- **代号。** 「同事甲」「友人·烛」是占位。正式代号由 Human 指定。真名不进入正文。
