## 1. 顶层哲学

### 1.1 为何记录

**遗忘不是记忆的失败，而是记忆的默认工作方式。** 一个人一生中绝大多数上下文——某个决定为何在当时显得合理、某段关系在某个下午的实际温度、某种恐惧在被克服前的真实体积——在发生的当下就开始丢失，剩下的被不断改写以适应此刻的自我叙事。

记录在这部作品里不是为了对抗遗忘，也不是为了保存「真相」。它要保存的是**上下文**：让一个时刻可以被理解所需要的最小的场。事件是点，上下文是使点变得可解释的空间。传统日记保存点，本档案试图保存空间。

因此记录的对象不是成就、里程碑或情绪曲线，而是**「一个个体如何在时间中持续成为自己」**这个过程本身。这个过程不能被总结，只能被持续观看。

记录的第二层理由是**可交接性**。一个人的一生终会需要被别人读——无论是未来的自己、亲近的人，还是某个尚不存在的读者。如果上下文没有被保存，后来的读者只能拿到一个被反复重写过的、只剩结论的故事。档案想留下的是让他们可以自己重新理解的材料，而不是一个已经理解完毕的版本。

### 1.2 记录伦理

样本是活人，且是作者本人。这意味着伦理是双重的：既有**对他者的伦理**（不得替其决定、不得越权解释），也有**对自己的伦理**（不得美化、不得虐待、不得表演）。

伦理原则在此只陈述立场，其操作化形式见第 2.4 节「档案宇宙基本法则」。

- **不替样本决定。** 观察者可以写观察、倾向、假说，但不写「样本应该」。命令式动词不得进入档案正文。样本一生的意义由样本自己持有最终解释权，观察者只提供被观看的材料。
- **推断与事实分离。** 每条记录带证据等级。观察者不把自己的解释写成发生过的事。
- **可修订，不可抹除。** 记忆会改写，档案允许改写，但每次改写留痕。抹除只在两种情形下允许：涉及第三人隐私，或样本明确撤回。即便抹除，也保留「此处曾有一条记录被撤回」的标记。
- **第三人只写接触面。** 出现在样本生命中的其他人，只记录他们与样本相接触的那一面，不推测其内在，不为其代言。
- **不表演。** 生活不为档案而制造密度。档案接受稀疏、接受长期空白，并把空白如实标记为空白。
- **未来不做预言。** 关于未来的记录必须是可回访、可证伪的假说，不能是愿望、鸡汤或自我激励。
- **助手不越界。** 助手对观察者负责，不对样本共情、不给样本建议。它的伦理位置是「让观察更完整」，不是「让样本更好」。

### 1.3 第三人称自我观察的意义

第一人称有一种语法上的辩护本能：「我」在陈述自己时，会自动附带动机、理由、合理化。第三人称剥夺了这种优势。当作者写下「Zven 在那年秋天换了工作」而不是「我在那年秋天换了工作」时，句子失去了替自己解释的位置，只剩下描述。这不是冷漠，而是**解除辩护**。

第三人称的第二层作用是允许**矛盾并存**。第一人称叙事有一致性压力——「我」必须在故事里是同一个人。第三人称的样本可以是连续但不必一致的：他可以在同一年里既勇敢又逃避，档案不需要为此给出统一解释。

把作者拆成三个角色，不是对精神分裂的浪漫化，而是一种**写作装置**。它把三种在日记里纠缠不清的东西分开：

- **想记录的冲动**（观察者）——它有情感、有偏好、会在某些地方停留更久；
- **整理与追问的能力**（助手）——它没有情感任务，只负责让观看变得完整；
- **被生活的身体**（样本）——它不需要为档案负责，只需要活着。

三者分开后，每一方只做自己的事，写作才有可能长期持续。

第一人称并未被驱逐。它以**「样本自述摘录」**的形式存在：被引用、被标注时间与证据等级、被置于证据链之中。它是材料，不是叙事声音。这一区分决定了作品的基本语调。

### 1.4 科幻壳与情感核如何互证

**科幻壳提供距离与许可。** 观察站的冷静语法允许写出在日记里说不出口的事。「样本在此期间的睡眠结构出现持续性断裂」比「我那段时间失眠得很厉害」更容易被写下，也更容易被日后的自己读下去。距离不是为了逃避，而是为了让书写可以持续。

**情感核提供重量。** 如果观察者对样本毫无情感投入，档案就只是数据堆。但情感在这部作品里有严格的流露方式：不通过抒情，而通过**选择**——记什么、不记什么、在哪个 Node 停留更久、回访哪条假说、在何处保持沉默。观察者的偏爱是结构性的，不是修辞性的。

**反差是基本审美律：语言越克制，被记录之物越重。** 这条律法约束所有下游写作语气。

**两者互证的方式：**

- 科幻壳的可信度来自情感核的真实。读者愿意相信这个观察站存在，是因为它观看的这个人是真的、这份注意力是真的。
- 情感核的可承受度来自科幻壳的距离。作者能把这件事写十年、三十年，是因为不必以第一人称承受每一次书写。

观察站的**限制**是情感核的入口。它不能改变样本、不能读取样本未留下痕迹的内心、观看有盲区、观察者与样本同步老去。一个全知全能的观察站没有情感可言；一个有局限、会遗漏、只能等待的观察站才会让「记录」这件事本身带有重量。

### 1.5 全生命周期上下文的哲学定义

**它不是传记。** 传记是叙事完成品，有起承转合，有作者对一生的定论。本档案永远没有定论。

**它不是数据集。** 数据集是无解释的堆积。本档案的每条记录都带着「当时如何被理解」与「后来如何被重新理解」。

**它是上下文档案：让任一时刻的样本可被理解所需的最小充分场。**

上下文分三层：

1. **事实层**——发生了什么，带证据等级；
2. **解释层**——当时如何被理解，包括样本自己的理解与观察者的理解，两者分开标注；
3. **修订层**——后来如何被重新理解，每次修订是一次新的观看。

「全生命周期」的边界向两端延伸：向前到出生前的**溯源**（家族、时代、地理——记录的是它们如何被样本携带，而非家族史本身），向后到死亡后的**交接**（谁接手、如何读、档案的终态）。两端的具体处理均待拍板，见第 4 部分。

**覆盖 ≠ 完整。** 档案的目标不是覆盖一生的每一天，而是在任一被记录的时刻做到**连贯**（这个 Node 与它前后的 Node 能互相解释）与**可交接**（一个不认识样本的读者能读懂）。「完善」是渐近的，不是完成的；档案永远处于「当前版本」。

### 1.6 人生意义作为引力而非答案

作品不回答「人生的意义是什么」。这个问题在档案正文中不得以陈述句出现。

意义在这里是一个**方向场**（Orientation）。它像引力：本身不可见，但解释了轨迹为何弯曲。它解释观察者为何在某些 Node 停留更久、为何某些假说被反复回访、为何某些主题锚点横穿几十年而另一些只出现一次。

引力**只以结构方式存在**：

- 在主题锚点的选择里；
- 在回访的频率里；
- 在观察者的沉默处；
- 在样本自述摘录被引用的位置里。

引力会被修订。今天看来重要的方向，十年后回访时可能被降格为一次偶然。档案如实记录这种变化，不把任何一版方向场固定为最终答案。

引力允许缺席。样本一生中必然有意义感稀薄、方向不明的时期。档案把这些时期如实标记为**「引力弱区」**，不填补、不美化、不回避。弱区本身是重要的上下文。

这一节服务于观察者的观看目的：观察者不是为了给样本的一生定性，而是为了看清这条轨迹在什么场中弯曲过。至于这条轨迹「值不值」，档案不作答，也不允许助手作答。

## 2. 世界观

### 2.1 观察站与高维文明：设定边界

设定原则：**够用即可**。观察站是一个「位置」，不是一段文明史。宇宙论越多，人的戏越少。

**明确写入的（最小充分设定）：**

- 存在一个能够跨越样本时间轴观看的位置，称为观察站。
- 观察站有一位观察者。观察者的任务是记录，不是干预。
- 观察者被配给一位助手。助手的任务是让观察更完整。
- 观察站的「高维」能力，**就是档案的能力**：并置三态时间、回访假说、保留修订史、标注证据等级。不再另外发明超能力。
- 观察站有限制：不能改变样本；不能读取样本没有留下痕迹的内心；观看有盲区；观察者与样本在同一条时间里老去。

**明确不写的（留空，非待填，而是刻意空白）：**

- 高维文明的社会结构、科技、历史、动机。
- 为何选中 Zven。
- 是否存在其他样本或其他观察者（默认：档案内不出现）。
- 观察站的物理形态、位置、外观。
- 观察者的来历、名字以外的身份信息。

这些空白是世界观的一部分。读者会追问，档案不回答。追问本身构成作品的呼吸。

#### 2.2.2 声音分层原则

三种声音必须在任何载体上**可被瞬间区分**。这一原则的具体实现（排版、色彩、标记符号）交给下游信息架构与视觉设计，本稿只规定：

- **正文声**（观察者 / Observer）：作品的主体。读者默认读到的是它。
- **边注声**（Margo）：永远处于正文之外，可被折叠或忽略而不影响正文完整性。它的存在让读者看见「观看是如何被组织的」，但它不参与叙事。
- **摘录声**（样本）：以引用形式嵌入正文，必带三项标记——时间、证据等级、「样本自述摘录」字样。

#### 2.2.3 声音示意（非真实档案内容，仅示语气）

> **正文声（观察者 / Observer）**
> Zven 在这一年的秋季更换了居住地。搬迁前后各有约两周的记录缺失。我在缺失处停留了较久。

> **边注声（Margo，对观察者）**
> 缺口：搬迁前两周无任何现场态 Node。建议回访时补一条溯源态，证据等级预设为「回忆」。另，本 Scenario 中「居所」锚点的未来态假说尚无回访日期。

> **摘录声（样本自述摘录 · 回忆 · 时间待补）**
> 「那时候我觉得搬走就能重新开始，现在想想其实什么都没变。」

#### 2.2.4 关系链的两个流向

- **信息流向**：样本留下痕迹 → 观察者观看并书写 → 助手整理并追问 → 观察者补录或修订。
- **权限流向**：样本对自身意义拥有最终解释权 → 观察者拥有书写权 → 助手拥有提议权（无决定权）。

两个流向方向相反，这是三角结构稳定的原因：信息从样本流向助手，权力从样本流向助手时逐级递减。助手掌握最多的整理信息，却拥有最少的决定权。

### 2.3 时间与因果

#### 2.3.1 时间三态

| 时态 | 名称 | 记录的实际对象 | 证据特征 | 默认命运 |
| --- | --- | --- | --- | --- |
| 过去 | 溯源 | 不是过去本身，而是「现在如何记得过去」 | 证据等级偏低，可修订 | 被反复重写 |
| 现在 | 现场笔录 | 正在发生或刚发生的事 | 证据等级最高，解释最少 | 随时间沉降为过去态 |
| 未来 | 假说 | 观察者对样本轨迹的可证伪推测 | 无证据，只有回访条件 | 被回访：成立／不成立／无法判定 |

关键立场：

- **过去态是可修订的记忆。** 每一次重写溯源态，档案记录的其实是「此刻的样本如何理解过去的样本」。溯源态的修订史本身就是一条关于样本变化的证据。
- **现在态是最贵的。** 它无法事后补录。现场笔录允许粗糙、允许无解释，因为解释可以后补，现场不能。
- **未来态不是愿望。** 一条合格的未来态 Node 必须包含：假说内容、回访时间点、什么情形下算不成立。不满足这三项的未来态不得写入。
- **假说不成立不是失败。** 它是样本发生了变化的直接证据，往往比成立的假说更有价值。

#### 2.3.2 并置而非线性

三态**不按时间轴排列**，而是经**主题锚点**横向拉齐、三栏并置。一个锚点（例如「居所」「身体」「工作」「某段关系」「注意力」）下，读者同时看到：样本过去如何、现在如何、观察者对其未来如何假说。

主题锚点的初始集合待拍板。本稿只规定它的性质：锚点是横穿三态的主题线，可以横跨几十年，也可以只出现在一个 Scenario 里；锚点数量不设上限，但每个锚点必须至少有两个时态有内容才成立。

#### 2.3.3 两条时间轴

档案区分**事件时间**（事情发生的时间）与**档案时间**（这条记录被写下或修订的时间）。两条轴永远同时标注。它们之间的距离本身是信息：一条事件时间在二十年前、档案时间在昨天的溯源态 Node，与一条两者相差三小时的现场态 Node，可信度与性质完全不同。

#### 2.3.4 因果的谨慎

档案不把因果写成事实。「因为 A 所以 B」在正文中只能以假说形式出现，并可被回访。观察者可以并置 A 与 B，可以写「我注意到 A 之后出现了 B」，但「A 导致 B」是一条需要证据等级和回访日期的推测。

这条规则的哲学依据是：对自己一生的因果解释是最容易被自我叙事污染的部分。第三人称与证据等级在这里共同构成防线。

#### 2.3.5 修订史

- 每次修订都是一次新的观看。旧版不删除，可查。
- 修订本身是内容而非元数据。读者看修订史时读到的是「样本对自己理解的演变」。
- 修订粒度（逐字／逐 Node／逐 Scenario）待拍板。

#### 2.3.6 假说回访

- 每条未来态 Node 自带回访时间点。助手负责提醒，观察者负责回访并书写结果。
- 回访结果三种：**成立**、**不成立**、**无法判定**。三种结果地位平等。
- 回访结果作为新 Node 写入，关联原假说；原假说不修改。
- 一条假说可以被多次回访。

### 2.4 档案宇宙基本法则

以下十条是档案宇宙的「物理定律」。下游一切设计与写作不得违反；若发现冲突，修改下游而非法则。修改法则本身须由作者拍板。

1. **不干预律。** 观察站不改变样本。档案内一切「建议」「目标」「优化」「提醒样本去做某事」均不成立。这是对前作的明确反转。
2. **证据律。** 每条记录标注证据等级。推断不得伪装成事实。等级档数与命名待拍板。
3. **修订律。** 可改不可抹。修订留痕，旧版可查。抹除仅限第三人隐私与样本撤回两种情形，且留下「此处曾有记录」的标记。
4. **主权律。** 样本对自己一生的意义拥有最终解释权。观察者只写观察与假说，不替样本决定「这一生是什么」。
5. **第三人律。** 他者只写与样本的接触面。不推测其内在，不为其代言。称呼规则已定，见 §4.4。
6. **沉默律。** 不记录也是一种记录。空白必须被标记为空白（缺口），而不是被填补或掩盖。
7. **交接律。** 档案默认有一个尚不认识样本的未来读者。一切写法以「可被此人读懂」为准。
8. **助手边界律。** 助手只对观察者说话。它不进入正文，不对样本发言，不共情，不给建议。
9. **人称律。** 正文以第三人称书写样本。样本第一人称只能以「样本自述摘录」形式出现，且必带时间、证据等级、摘录标记。
10. **反鸡汤律。** 未来态不得写成愿望；意义不得写成结论；观察者不得替样本鼓劲。克制是唯一允许的温度。

### 2.5 结构词汇的概念定义

以下只定义概念与相互关系，不规定数据结构或界面。

- **Dossier（档案卷）**：一个样本的全生命周期上下文。整部作品只有一卷。它没有「完成态」，只有「当前版本」。
- **Scenario（情境）**：档案内一个有内在连贯性的上下文场。它**不是章节、不是时间段**，而是「一组可以互相解释的 Node 所构成的场」。一个 Scenario 可以横跨多年，也可以只是一个下午。Scenario 之间可以重叠。
- **Node（节点）**：最小可记录单位。每个 Node 必带：时态（溯源／现场／假说）、事件时间、档案时间、证据等级、修订史。可选：所属 Scenario、主题锚点、关联 Node、回访条件（假说态必带）。
- **主题锚点**：横穿三态的主题线，是三栏并置的依据。见 2.3.2。
- **证据等级**：标注一条记录与「发生的事」之间的距离。示意档位——现场／近场／回忆／转述／推断——仅为说明性质，具体待拍板。
- **修订史**：一个 Node 或 Scenario 的所有历史版本及其档案时间。见 2.3.5。
- **假说回访**：见 2.3.6。
- **缺口**：被标记的空白。助手的核心产出之一。缺口可以被填补（产生新 Node）、被确认为永久空白、或被保留为待回访。
- **认知 × AI 时代索引**：一组横切的时代维度索引，例如注意力、人机边界、知识代谢、记忆外包等。它的性质是**索引而非表格**——不要求每日填写，只在某个 Node 触及该维度时打上标记，供日后横向检索。设立它的理由有二：其一，Zven 生活的年代恰是人机边界被重构的年代，这是样本上下文不可省略的一部分；其二，这部作品本身的记录者配有 AI 助手，索引让作品对自身处境保持自反。具体维度集合待拍板。

## 3. 作品／生命记录双身份

### 3.1 作为可读的互动写作实验作品

- **任意入口。** 读者可以从任何一个 Node 进入并读懂它，因为每个 Node 自带时态、时间、证据等级与上下文关联。作品不要求从头读。
- **读到的是「观看的方法」，而非故事。** 作品的实验性在于：读者跟随的不是情节，而是一种持续、克制、有伦理约束的观看方式。三态并置让读者同时看见样本的过去、现在与被假说的未来，并自行感受三者之间的落差。
- **「档案在活着」的证据。** 修订史与假说回访让读者看见这卷档案随时间变化。一条三年前的假说在上周被标记为「不成立」，这比任何叙事技巧都更能让人感到时间的重量。
- **边注声是作品的一部分。** 助手的缺口清单、回访提醒让读者看见观看的组织过程。它是作品自反的层面，但可被折叠——读者可以选择只读正文。
- **反差作为阅读体验。** 读者进入时面对观察站的冷静语法，读下去时逐渐感到这份注意力背后的重量。反差不是设计出来的，是克制语法与真实生命相遇的自然结果。

### 3.2 作为可长期使用的生命档案

- **写入门槛低。** 一个 Node 就是一次记录。不要求结构完整，不要求每日。一条粗糙的现场笔录比一条精致的事后重构更有价值。
- **允许长期空白。** 依沉默律，空白被标记而非填补。几个月不写不构成档案的失败，只构成一个缺口。
- **修订是常态。** 档案不要求第一次写对。溯源态本来就是可修订的记忆。
- **助手降低维护成本。** 追问缺口、提醒回访、对齐三态、标注证据等级——这些是助手的工作，不是观察者的负担。观察者只需要观看和书写。
- **可交接。** 依交接律，档案始终为一个未来读者书写。这使它在作者本人之外仍能被读懂、被接续。

### 3.3 两种身份的张力与调和

| 张力 | 调和原则 |
| --- | --- |
| 作品需要密度，生活不需要表演 | **不为作品制造生活。** 作品接受稀疏。若某段时期没有值得记录的事，档案如实空白。稀疏本身在作品中是有意义的节奏。 |
| 作品面向读者，档案涉及隐私 | **分层公开。** 哪些 Node、哪些 Scenario、哪些证据等级对外可见，由作者拍板。本稿只确立原则：公开程度是 Node 级属性，默认从最保守设置开始。 |
| 作品需要语气一致，生活的记录是即时的 | **语气约束只加于观察者正文声。** 样本自述摘录保留原始语气不修饰；现场态笔录允许粗糙。一致性由第三人称与证据标记保证，不由文笔保证。 |
| 作品会被评价，档案不应因评价而改变 | **主权律优先。** 读者的反应不构成修订理由。修订只能来自观察者新的观看。 |

### 3.4 载体倾向为网站的概念含义

本节不涉及 UI，只说明「网站」作为载体在概念层意味着什么：

- **每个 Node 有一个持久地址。** 可被引用、可被链接、可被交接。这与 App 内的私有数据根本不同。
- **持久性优先于即时性。** 网站没有推送、没有打卡、没有连续签到。它不催促样本，这与不干预律一致。
- **三栏并置是网页天然擅长的事。** 时间三态经主题锚点横向并排，在网页上比在移动端竖屏更自然。
- **公开与私密的分层可以在地址层面实现。** 具体机制留给下游。

### 4.3 证据等级

- 档数（三档／五档／其他）。
- 各档命名与定义边界。
- 样本自述摘录的证据等级如何标（按摘录时与事件时的距离？按自述时的状态？）。

### 4.4 第三人策略

**已锁定。** 档案正文中的第三人一律写作作者指定的、相对样本 Zven 的代号。寻常之人按与样本的关系给代号；特别的人用特别代号。档案正文不出现真名。

仍开放：

- 是否允许第三人对自己相关的 Node 提出撤回请求。

### 4.5 公开与私密分层

**已锁定：分级／分层发布。** 可见性是 Node 级属性，Scenario 级可选。默认保守。发布什么由作者选择。

仍开放：

- 是否存在「仅交接人可见」层。

### 4.6 生命周期的两端

- 溯源是否延伸到出生前（家族、时代、地理），延伸多远。
- 样本死亡后的档案终态：封存／交接人继续修订／自动公开／其他。
- 交接人的指定机制与权限。

### 4.7 结构参数

- 主题锚点的初始集合。
- 修订史的粒度。
- 认知 × AI 时代索引的具体维度集合。
- 一个 Node 是否可以同时属于多个 Scenario（本稿倾向允许）。

### 4.8 叙事边界

- 是否允许样本与观察者在作品内直接对话（打破三角的单向性）。本稿倾向不允许，但承认这是一个有张力的实验选项。
- 是否允许观察者在正文中使用第一人称「我」；若允许，频率上限如何把握。
- 是否保留前作「偶发跃迁」等语气遗产，以及以何种方式保留（见附录）。

### 4.9 语言

**已锁定。** 允许双语。样本自述摘录可以保留原语言。
