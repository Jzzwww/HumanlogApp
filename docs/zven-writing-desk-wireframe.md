# Zven 写作与档案阅读：概念线框

> v0.1 草案 · 2026-09-28。把 IA v0.2 落成可逐屏讨论的区块与动作；交付止于概念线框，尚未获得设计认可。
> 主线：**碎片 → 归维提议 → Human 确认 → 落盘 → 按维组装阅读**。人称与助手只影响书写姿势。
> 本文不定义色板、控件库、应用路由、账户或权限实现，也不修改上游的命名与发布政策。

以下以宽屏阅读顺序示意。正文与边栏并列时，正文约占可用宽度的三分之二，边栏约占三分之一；边栏收起后，正文保持完整。三态视图另用三个等宽区域，以便同时比较。这里只给结构比例，不定像素、字体或组件。

## 1. 整体怎么走

依据：IA §1.1–1.4、§5、§6；维度 §1.3、§4、§7。

```text
入口
 ├ 作者 → 写作桌 → 输入层 → 观察者过程面：归维确认
 │                            ├ 新 Node → 持久地址
 │                            ├ 并入既有 Node → 原地址、保留修订史
 │                            └ 待归维队列 ↔ 观察者过程面
 ├ 作者 → Dossier：整卷浏览
 └ 读者 → Dossier 的公开可达部分

档案阅读：
 Dossier ↔ Scenario ↔ Node
    ├ 按维拉出 ↔ Node ↔ 锚点 × 三态行
    └ 按维拉出 → 多维交集 ↔ Node
 Node ↔ 关联 Node；假说 Node ↔ 回访结果 Node
 Node → 同一地址上的修订史
```

读者可以直接打开有权到达的 Node 或独立可达的读法视图，不必从入口逐级进入。公开子集使用同一套 Node 地址；上图不再复制一套「公开档案」。Node 的地址不以 Scenario 为前缀。

## 2. 屏 A：入口

依据：IA §2.1、§5.1、§6.1；维度 §6.1；母文档 §3.1、§4.2。

```text
《Zven 卷》〔推荐未锁〕
一卷档案 · 当前版本

作者的下一跳：写作桌 / 档案
读者的下一跳：档案的公开可达部分
```

入口先交代这是一卷持续修订的档案。作者可开始输入，也可直接读档案；读者进入公开可达部分。作者／读者是访问处境，三角角色是同一作者的书写装置，不画成三个账户。如何识别访问者留给后续实现。

公开子集为空时，入口仍能到达可读面，其内容区显示 **「此处无公开内容」**。不加发布催促，不用未公开记录填充。观察站只作通名，不另造文明史页面；入口不设「留档／被听懂」的必选关卡。

## 3. 屏 B：写作桌的输入层

依据：IA §1.1–1.4、§5.1、§6.2；维度 §2.1–2.4、§4.1–4.2、§7.2–7.4。

```text
写作桌                                      → 档案

输入层
  〈碎片；可继续写，也可留下未完成的内容〉
  〈附着于这条碎片、尚未确认的归维提议〉

→ 观察者过程面：归维确认
→ 待归维队列

可选姿势：观察者过程面 / Zven 过程面
```

**先有输入位置，再有归维。** 输入前不要求选维度、时态、证据档或人称，也不要求先选姿势。原材料可以粗糙、错序、混合语言；是否收录在后续确认时处理。收录偏好可由 Human 取舍，但不豁免母文档的不干预、第三人、人称等已锁规则。

未落盘内容按 IA 的工作默认站内持存，跨场仍在，但没有持久地址。这里不出现引用、交接或公开入口；这些碎片不进 Dossier 和读法视图。输入层为空时留下可输入的位置；未收录、未确认不画成缺口。

归维提议附着在碎片上，呈现为无声的标记。需要解释时进入观察者过程面的 Margo 边栏。进入确认区只是换到能作书写决定的位置，**不等于确认，也不等于落盘**。

可选姿势只改变书写处境：观察者面可第三人称起草并查看 Margo；Zven 面可第一人称输入，Margo 不在场。另一位助手若出现，只标「陪写〔暂名未锁〕」；它的话不进输入层、不参与归维，也不成为档案边注。其站内持存或站外私聊位置仍待拍板，本稿不补画对话页。换面不会带入对面的助手。

## 4. 屏 C：观察者过程面的归维确认

依据：IA §1.1、§1.5、§2.2–2.4、§3.1、§6.2；维度 §3.1–3.4、§4.1–4.2、§5；母文档 §2.2.4、§2.3.1。

```text
观察者过程面
┌ 主区，约 2/3 ────────────────────────────────────┬ 边栏，约 1/3 ────────────┐
│ 输入层：〈原碎片〉                               │ Margo · 玛戈             │
│                                                  │ 对观察者：               │
│ 归维提议                                         │ 〈归维解释〉             │
│ 内容维：〈归属与取值〉                           │ 〈证据 / 时间对齐〉      │
│ 结构维：〈逐项查看与确认〉                       │ 〈缺口 / 回访〉          │
│                                                  │ 可折叠                   │
│ 〈第三人称正文〉                                 │                          │
│ 样本自述摘录 · 时间 · 证据档（可无）             │                          │
│ 确认 / 改 / 拒；也可暂不处理                     │                          │
└──────────────────────────────────────────────────┴──────────────────────────┘
确认后的去向：新 Node / 并入既有 Node / 待归维队列
```

主区从原碎片读到提议，再读落盘后的声音与去向。提议不伪装成已生效的维度标记，Margo 的解释不混进正文。边栏折上不影响 Human 查看原碎片、逐项修改、拒绝提议或决定是否落盘。

### 4.1 内容维与结构维怎样展开

内容维沿用六维骨架：**认知判断、作品项目、技艺方法、关系接触面（代号）、时代索引、意义取向**。清单推荐未锁。只展开这条碎片触及的归属与取值；可多维、同维多值，不要求六维填满。方法名、方向词、第三人代号与项目代号沿用 Human 指定或确认的值，本稿不造示例名单。第三人只写相对 Zven 的接触面，正文不用真名。

结构维一并处理：

- **时间态**：溯源／现场／假说。事件时间与档案时间并置。未知事件时间保留缺口，不填造日期。
- **证据档**：显示所提议的一档及是否待复核。档数、名称与摘录定级仍待拍板，不在图里造固定菜单。
- **声音层**：写 Zven 的正文为第三人称；保留第一人称时放进「样本自述摘录」，连同时间与证据档，原语言、原语气保留。Margo 仍只在边栏。
- **可见性**：新记录默认不对外。系统不提议公开，不把公开选项作为归维建议。

档案时间、保守可见性、语言识别、既有代号匹配可按维度 §4.1 先填默认。**默认填入不构成自动落盘**；内容维、时间态、证据档、事件时间推断与新取值等仍由 Human 确认、改或拒。没有经 Human 确认的标记直接进入 Dossier。

假说态在主区显露三项：**假说内容、回访时间点、怎样算不成立**。缺一项时保留在输入层，不作为假说态落盘；不把愿望改写成合格假说，也不为凑齐字段编造内容。来源不明、判断未决如实保留，不把“完整”当成有信号碎片的输入门槛。

### 4.2 三种落盘去向与停留

- **新 Node**：通过收录标准、确认至少一个内容维及全部结构维后，得到一个持久地址。打开屏 G，看到的是同一次确认形成的记录，不再生成按维分身。
- **并入既有 Node**：Human 先明确要并入哪条，再确认作为修订或摘录进入。去往该 Node 的原地址，旧版和旧标记可查；不是覆盖原文后丢失历史。
- **待归维**：值得留、暂无内容维落点的记录，在结构维齐备后由 Human 确认进入屏 D。低置信提议指向这个去向，不由系统静默归入某维或自动落盘。
- **拒或忽略**：碎片仍可留在输入层，未确认的提议不生效。这里没有强制完成、倒计时或清空队列要求。

若系统提议新维度，只进入待归维的同型汇总，依维度 §5.3 由 Human 判断、命名并记录理由；线框不加“一键自动建维”。锚点与 Scenario 归属也只是提议，不能因标记相同而自动成场。

## 5. 屏 D：待归维队列

依据：IA §2.4、§6.2、§7；维度 §5。

```text
待归维队列                                 → 输入层

〈待归维记录〉 → 该记录的地址
  时间态 · 事件时间 · 档案时间 · 证据档 · 声音层
  可见性：默认不对外
  内容维：暂无落点
  → 观察者过程面：重新确认归维

〈同型汇总与新维度候选；如有〉
```

它是写作桌内的位置。这里的记录已过收录门、带全部结构维、有地址可引用，尚不按内容维进入组装视图，也不对外。**是否已是一条 Node 仍待拍板**；因此图中只称待归维记录，不给它另造第四种单位，也不先承诺归维前后的地址迁移方式。

队列不显示待处理数、不设上限与清空期限。空时只显示目前没有待归维记录，不用“全部完成”奖励语。同型汇总不另设说话区；若需要解释，回到观察者过程面的 Margo 边栏。升维须经过 Human 的判断，不用累计条数自动触发。

## 6. 屏 E：Dossier 的整卷浏览

依据：IA §2.1–2.3、§4.1、§5.1–5.2、§6.3；维度 §1.2–1.3、§3、§4.3、§6.1。

```text
Dossier · 当前版本

按维拉出
  认知判断 / 作品项目 / 技艺方法
  关系接触面（代号） / 时代索引 / 意义取向
  → 选择已有取值 → 屏 I

锚点 × 三态行 → 屏 H
〈本卷锚点清单〉

Scenario → 屏 F
〈Human 已成立的场〉

Node → 屏 G
〈已落盘记录，包含尚无 Scenario 或锚点的记录〉

〈挂在整卷上的缺口；如有〉
```

维度入口占先，不让按日流水、生命阶段或双轨入口接管整卷。三种档案单位仍是 Dossier／Scenario／Node；六个内容维是找到记录的入口，不是六个待完成栏目。清单沿用推荐未锁状态，后续增删经过升维／撤维程序。

每条 Node 的阅读入口带时态、两轴时间、证据档与已确认的维度标记；这里只提取已有内容，不自动写出一段人物结论。结构维留在记录信息中，也可在按维阅读时作为收窄条件，不变成另一组档案单位。

作者看到整卷当前可读内容。读者看到同一结构经可见性过滤后的部分，所有入口继续指向同一套 Node 地址。整卷级缺口沿用 IA §2.3 默认不对外。

作者尚未写入 Node 时，记录区如实为空，可回输入层；没有 Scenario 或锚点不妨碍 Node 独立存在。公开内容为空用「此处无公开内容」。空维度不要求补齐，不以覆盖率证明“更完整的我”。

## 7. 屏 F：Scenario

依据：IA §2.1、§2.3、§4.1、§5.2、§6.3；维度 §3.3、§6.1。

```text
〈Scenario：Human 命名的场〉                    → Dossier

〈目前所含 Node〉 → 各自的持久地址

锚点 × 三态行：只列本场 Node 触及的锚点
按维拉出：范围为本 Scenario

〈挂在本 Scenario 上的缺口；如有〉
作者可选择：Scenario 级可见性
```

场把能互相解释的 Node 放在一起，不以年份、年龄或同一标签自动生成。Node 可以先属于一处，也可以暂不属于任何场；多属 Scenario 仍待拍板，图中不画已定的多场选择机制。

从场进入维度视图时，保留“本 Scenario”的范围说明；改为整卷范围只是改变读法。返回 Node 后，其地址与从别处进入时一致。场内缺口在载体上可见，不依靠 Margo 展开才出现。

Node 与 Scenario 可见性冲突时沿用 **更严者生效〔工作默认／推荐未锁〕**。图中不把“公开整个场”画成批量公开其中 Node 的动作。过滤后没有内容仍用公开空态，不补出未公开 Node 的占位清单。

**直接打开也能读懂。** Node 自带时间、证据与关联，不依赖读者先读整卷。正文是不可折叠的主体；摘录嵌入正文且三项标记齐备；Margo 位于正文之外。结构标记不是第四个说话区。

收起 Margo 后，正文、摘录、时态、两轴时间、证据档与载体上的缺口仍在。没有边注时不生成凑数的话；没有摘录就不留一块空引语。

### 8.1 记录上的动作与阅读边

- 维度标记通往对应取值的按维视图；锚点标记通往三态行；Scenario 标记通往所属场。每处都能通过原 Node 返回。关联为空时保持为空，不要求补满。
- 作者修订正文或维度标记后仍在同一地址查看，旧版留在修订史中；不先锁逐字或逐 Node 的修订粒度。
- 从档案回输入层，是开始新的输入或修订过程，不把已落盘 Node 降回无地址碎片。读者阅读不因此打开编辑区或新的聊天区。
- 缺口解释可在 Margo 边栏汇总并指回载体；缺口本身的标记留在 Node、Scenario 或锚点行上。填补、永久空白、待回访三种去向沿用上游，不等于待归维或未收录。

### 8.2 假说回访

到期提醒只在本地址或观察者过程面的 Margo 边栏中出现，不出站、不推送。作者回访后走同一归维确认过程，把结果写成 **新 Node**，与原假说双向关联。原假说的内容与地址不改。成立／不成立／无法判定同等呈现；多次回访是多条结果记录，不覆盖成最新结论。

### 8.3 可见性附着在记录上

作者在 Node 上逐条选择发布内容；可见性不是必须经过的另一页。默认仍是不对外，系统不推荐公开。Scenario 存在额外限制时，按更严者生效，不因从 Node 直接打开而绕过。

公开前，作者能在同一条记录上读到正文、摘录和 Margo 边注；IA §3.2 的工作推导是三者随 Node 一起进入公开子集。线框不私自增加“公开正文、自动隐藏边注”的新政策。修订史旧版与撤回标记的公开范围尚无默认，见 §12。

## 9. 屏 H：锚点 × 三态行

依据：IA §2.3、§3.3、§4、§5.2、§6.3；维度 §3.3、§4.3；母文档 §2.3.2。

```text
〈主题锚点〉                    范围：整卷 / 某 Scenario

┌ 溯源，1/3 ─────────────┬ 现场，1/3 ─────────────┬ 假说，1/3 ─────────────┐
│ 〈Node〉               │ 〈Node〉               │ 〈Node〉               │
│ 两轴时间、证据档       │ 两轴时间、证据档       │ 两轴时间、证据档       │
│ → 该 Node 地址         │ → 该 Node 地址         │ 回访条件               │
│ 〈可有多条〉           │ 〈可有多条〉           │ → 该 Node 地址         │
└────────────────────────┴────────────────────────┴────────────────────────┘
作者侧空格：载体上的缺口标记
公开侧空格：此处无公开内容
```

一行先让三态一起被看见，再进入某条记录。宽屏用等宽三列；窄屏仍让同一锚点的三态名称与有无内容可同时辨认，正文继续从 Node 阅读，不改成一次只见一态的时间标签页。本稿只约束阅读关系，不定断点或滚动实现。

作者侧锚点不足两个时态有内容时标 **「尚未成立」**，已有 Node 照常可读。初始锚点集合不预填。锚点行独立可达，也可从整卷、Scenario 或 Node 锚点标记进入；可引用的稳定位置尚未锁定，不能把“独立可达”写成第二个持久地址。

公开侧仅摆放公开可达的 Node，空格统一用「此处无公开内容」，不据此推断没有记录或存在私密记录，也不从隐私内容补全三态。缺口标记与边栏的收展无关；其公开处理遵守 IA §2.3、§3.3 的载体规则及空格默认。

## 10. 屏 I：按维拉出与多维交集

依据：IA §2.2、§5.2、§6.3；维度 §3.2–3.4、§4.3、§6.3。

```text
按维拉出
内容维：〈一个内容维〉  取值：〈已有取值〉
范围：整卷 / 某 Scenario
→ 加入其他维度取值，形成多维交集

〈当前条件〉
〈Node〉：已有正文内容、时态、两轴时间、证据档、维度标记
  → 原 Node 地址
〈Node〉 → 原 Node 地址
```

项目史、代号史、改判史与时代索引横向检索，都是这一屏换取值后的读法，不各造一套栏目。项目代号由 Human 指定；代号史只读 Zven 与第三人的接触面。代号表与项目代号表只是取值来源，本身不公开，位置仍未锁定。

从一个内容维继续加入取值，可读多维交集；必要时结合时间态等结构信息收窄。范围和条件留在结果上方，读者知道正在看哪部分。撤去条件回到较宽读法，不改 Node 的标记、内容或地址。

按维视图独立可达；多维交集可达但不承诺稳定位置。结果只组装已有 Node，不自动生成“Zven 是怎样的人”的总结。若观察者另写理解，要通过写作流程成为带推断档的新 Node，不能回写旧碎片，也不能多出系统叙述声。

作者筛选无结果时，如实说明当前条件下没有记录，可撤去条件。读者过滤后为空时用「此处无公开内容」。不把一次无结果当作缺口，不纳入待归维记录；读者能到达的每条结果仍受自身可见性约束。

## 11. 屏 J：公开阅读态

依据：IA §3、§5、§6.1、§6.4；维度 §6.3；母文档 §3.1、§3.3、§4.5。

这不是新页面树。屏 E–I 在读者处境下，沿用各自区块与原 Node 地址，只呈现公开可达部分：

```text
入口 → 整卷 / Scenario / 读法视图 → 公开 Node 的原地址
读者也可直接打开公开 Node 或独立可达视图

Node 内：观察者正文 + 样本自述摘录（可无）+ Margo 边栏（可折）
结果为空：此处无公开内容
```

公开一条 Node 前后，其地址相同；在多个读法中出现也仍是一条记录。整卷、Scenario、维度、锚点、关联 Node 和回访关系的可达内容一并按可见性过滤，不借关联入口进入未公开记录。

输入层、过程面、未确认提议、待归维队列、陪写的话与代号表均不进入这里。访问者即使持有未公开地址，也不能由此读到其内容；具体访问校验与响应方式不在本稿定义。不新增「仅交接人可见」层。

公开侧读到的仍是当前版本，不是人物定论。没有评论驱动修订、打卡、完成度或催发布的区块。

## 12. 留给拍板的位置

依据：IA §7；维度 §9；母文档 §4。以下都是上游已有开放项。本稿把它们对应到影响的屏幕，便于后续决定，不将“暂未画”解释为新禁令。

- **旧版修订史是否随公开、撤回标记是否在公开侧可见**：影响屏 G、J。作者侧可查历史；仅在涉及第三人隐私或样本明确撤回时允许抹除，原地址留下「此处曾有一条记录被撤回」，维度标记去掉、标记修订史保留（母文档 §2.4 第 3 律；维度 §6.3）。公开侧的旧版入口与撤回状态暂不画完整行为，不默认公开，也不声称已经决定永不公开。
- **待归维记录是否即 Node**：影响屏 C、D。先保留已有地址、全部结构维、不进视图、不对外；不定义新单位或地址迁移。维度 §2.1 与 §5.2 的措辞出入由上游决定。
- **Node 与 Scenario 的可见性覆盖、公开空格的解释**：影响屏 F–J。继续用 IA 推荐未锁的“更严者生效”和“此处无公开内容”，不代终锁。
- **视图稳定位置、Node 多属 Scenario、修订粒度**：影响屏 F–I。只承诺 Node 持久地址；Node 属于一处或暂无；历史可查但不定粒度。
- **证据档数与名称、摘录定级、内容维及其取值、时代索引集合、锚点初始集合、置信度显示与升维阈值**：影响屏 C–I。保留字段与程序，不造枚举和数字。
- **标题、定位语、样本称呼、实名公开程度、观察站专名**：影响屏 A、E、J。沿用带状态的工作标签，不添新名字。
- **样本与观察者对谈、观察者“我”的频率、前作语气遗产、陪写的命名与持存位置**：影响屏 B、C、G。本稿沿三种声音，不预设对谈区或另一助手的页面。
- **仅交接人可见、第三人撤回请求、生命周期两端与交接机制**：不预设权限层、申请流程、阶段关卡或终态页面。

## 13. 用这些走读检查线框

这里检查的是文档能否讲通真实路径，不声称已有产品行为或运行测试。`〈碎片〉`、`〈Node〉` 均为结构占位，不调用样本页文案作为风格范本。

1. **第一次写入**：作者从 A 到 B，直接留下碎片；进入 C 后改或拒提议。未确认时没有档案地址。确认收录后，到 G 得到唯一 Node 地址，默认不对外。
2. **第一人称材料**：在 B 以 Zven 姿势输入；Margo 不出现。进入 C 由观察者确认，原话带时间、证据档和摘录标记进入 G，或由 Human 改成第三人称；陪写的话不跟随。
3. **暂不归维**：有信号但暂无内容维，结构维齐备后到 D。记录可引用、不进 I、不进 J；重新确认回 C，不强称 Node，也不假定地址如何迁移。
4. **一条多维**：G 上两处内容维标记分别进入 I；两个读法都返回同一 G。再收窄交集，原记录不被复制或改写。
5. **独立阅读**：直接打开 G 可见两轴时间、证据与上下文关联；从 G 到 H 再返回原地址。收起 Margo 后，正文、摘录与载体上的缺口仍可读。
6. **假说与回访**：三项不齐留在 B；齐备后经 C 落盘。到期只在 Margo 边栏提醒，回访形成另一条 G，原假说不改，两条双向可达。
7. **公开过滤**：Human 逐条选出 Node，Scenario 若更保守仍不能到达公开侧；有效公开后，J 使用原地址，I、H 中也只出现可达记录。为空只显示「此处无公开内容」。旧版与撤回的公开行为停在 §12 的未决处。
8. **不必写满**：无 Scenario、无锚点、无摘录或长期空白都能成立。没有每日必填、六维完成率、队列待处理数，也没有第六项核心元素的空槽。
