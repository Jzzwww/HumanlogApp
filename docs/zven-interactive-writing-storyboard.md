# Zven 互动写作分镜

> 文档性质：互动写作的分镜，不是功能清单，不是线框。它描述同一作者在一张档案桌上如何分饰三角、声音落在哪里、一次书写如何发生。
> 上游：`docs/zven-lifecycle-dossier-philosophy-worldview-outline.md` **v0.1.2**（下称母文档）；命名槽对照 `docs/zven-lifecycle-dossier-naming-draft.md` **v0.1.2**。依据分支为命名验收与 §4 收束之后的文本（PR #3，`cursor/zven-naming-acceptance-backfill-5f7d`）。
> 版本：分镜 v0.1。凡场面依赖母文档处，注明章节。母文档标「待拍板」或「推荐未锁」的，本分镜不升格为已定。
> 校正对象：仓库内没有更早的分镜文件。本稿相对命名验收前的对话默认（空着的元素 6、观察者／助手候选专名、前作里面向样本的建议）改写。对照见文末。

文中引号内的档案句子均为**语气示意**，沿母文档 §2.2.3 的尺度，不是作者实录，也不是已锁定的首条档案。

## 0. 前提／一句话定位

**板上只有这一句在工作：**

> 一位高维观察者，在一位 AI 助手的辅佐下，以第三人称持续记录地球人类样本 Zven 的一生——过去、现在、未来并置——目的不是写成传记，而是让这个个体在任一时刻都能被理解、被接续。

（母文档 §0.1）

同一作者拆成三个角色，坐在同一张桌上。互动发生在**观察者与 Margo·玛戈**之间：书写、缺口、证据、时间对齐、回访。样本 Zven 被记录，不成为对话的另一方。

产品目标放在这张桌上的方式：一次次 Node 逐渐补上这一个地球个体的全生命周期上下文。覆盖不等于完整；连贯与可交接优先于传记式的收束（母文档 §1.5、§3.2）。档案没有完成态，只有当前版本（§2.5）。

人生意义不占一页。它以引力（Orientation）存在：方向场，解释轨迹为何在某些地方弯曲，不以结论句出现（§1.6）。

**推荐未锁，分镜只当工作标签，不当已定名**（母文档 §4.2，命名草案 §3）：

| 项 | 工作标签 | 状态 |
| --- | --- | --- |
| 对外标题 | 《Zven 卷》/ *The Zven Dossier* | 推荐未锁 |
| 样本称呼 | Zven | 推荐未锁 |
| 定位语 | 不是传记。是一卷始终处于当前版本的档案。/ *Not a biography. A dossier, always at its current version.* | 推荐未锁 |

页眉若需要一行字，用上表，并带着「推荐未锁」。观察站没有专名；观察者不取专名（§2.1、§4.2）。

**元素 6 不在这张桌上。** 它已取消（误触），不再保留空位，不发明第六项核心元素，桌面也不留空着的第六槽（§0.2 第 6 条、§4.1）。

依据：§0.1、§0.2、§1.5、§1.6、§2.1、§2.5、§4.1、§4.2。

## 1. 角色三角与声音层

### 1.1 同一作者，三个角色

硬三角（§0.2、§2.2）：

```
Margo·玛戈  →  辅佐  →  观察者 / Observer  →  记录  →  样本 Zven
（AI 助手）              （无专名）                         （第三人称）
```

关系单向。信息从样本留下的痕迹流向观察者，再流向 Margo 的整理与追问，最后回到观察者的补录或修订。权限相反：样本对自身意义有最终解释权，观察者有书写权，Margo 只有提议权（§2.2.4）。

三人是写作装置，不是三个产品用户，也不是对分裂的戏剧化（§1.3）：

| 角色 | 在桌上的职能 | 作者何时戴这顶帽子 |
| --- | --- | --- |
| 观察者 / Observer | 执笔。决定记什么、在哪里停留、是否沉默 | 在正文区落笔时 |
| Margo·玛戈 | 整理、追问缺口、对齐时间、提议证据等级、提醒回访 | 读边栏、决定采纳或忽略时 |
| 样本 Zven | 被记录的那一个生命。活着。对档案有主权 | 生活发生时；第一人称只在被标记的摘录里被引用 |

### 1.2 谁在界面的哪里说话

三种声音必须能被立刻分开（§2.2.2）。排版与色彩交给日后的线框；分镜只规定位置。

| 声音 | 说话者 | 落点 | 人称 | 折叠后 |
| --- | --- | --- | --- | --- |
| 正文声 | 观察者 | 主书写区。读者默认读到的就是它 | 写样本用第三人称。观察者的「我」可以出现，宜少，只标记停留与不确定（频率上限仍开放，§4.8） | 不可折叠。它是作品主体 |
| 边注声 | Margo | 主区之外的边栏：缺口、回访提醒、证据提议、时间对齐。可折叠 | 对观察者称「你」。提及样本用「样本」或「Zven」 | 折上后正文仍然完整 |
| 摘录声 | 样本 | 嵌在正文里的引用块 | 块内第一人称。块外立刻回到第三人称 | 作为材料留在正文里，不是第二条叙事 |

摘录块必带三项标记：时间、证据等级、「样本自述摘录」（§2.2.2、人称律 §2.4 第 9 条）。允许保留摘录的原语言（§4.9）。

**Margo 的位置只有边栏。** 它不进入档案正文，不以角色身份对 Zven 说话，不共情，不说教，不给样本生活上的建议（助手边界律，§2.2.1、§2.4 第 8 条）。正文里不出现「玛戈对 Zven 说」。

观察者不命令样本，不写「样本应该」，不替样本总结一生（§1.2、主权律）。

### 1.3 声音示意（非真实档案）

> **正文声（观察者）**
> Zven 在这一年的秋季更换了居住地。搬迁前后各有约两周的记录缺失。我在缺失处停留了较久。

> **边注声（Margo，对观察者）**
> 缺口：搬迁前两周无任何现场态 Node。回访时可由你补一条溯源态，证据等级预设为「回忆」。本 Scenario 里「居所」锚点的未来态假说还没有回访日期。

> **摘录声（样本自述摘录 · 回忆 · 时间待补）**
> 「那时候我觉得搬走就能重新开始，现在想想其实什么都没变。」

边注里的「建议」只针对档案动作（补一条溯源、标一个回访日），对象是观察者。它不变成「建议 Zven 如何生活」。

依据：§0.2、§1.2、§1.3、§2.2、§2.4 第 8–9 条、§4.2、§4.8、§4.9。

## 2. 时间层：一张桌上的溯源／记录／展望

三态并置，不排成一条必须从出生走到死亡的时间轴（§2.3.2）。命名草案所记的作者决定在此生效：**生命周期不设限，叙事边界不设限**——先随意记录，之后由 Margo 协助整理。整理是提议，不是写作前的关卡。

桌上三层的工作名：

| 分镜称呼 | 母文档时态 | 实际记录的是 | 默认命运 |
| --- | --- | --- | --- |
| 过去 · 溯源 | 过去 / 溯源 | 现在如何记得过去，不是过去本身 | 可被反复重写；修订史留下 |
| 现在 · 记录 | 现在 / 现场笔录 | 正在发生或刚发生的事。解释可以后补，现场不能 | 证据最贵；随时间沉降为过去态 |
| 未来 · 展望 | 未来 / 假说 | 可证伪的推测 | 回访：成立 / 不成立 / 无法判定 |

「展望」只是这张桌上对未来层的称呼。写进未来层的句子必须是假说，含三项才合格：假说内容、回访时间点、何种情形算不成立（§2.3.1）。愿望、鼓劲、自我激励不进这一层（反鸡汤律，§2.4 第 10 条）。假说不成立不是失败，往往是样本发生变化的证据（§2.3.1）。

### 2.1 它们如何坐在同一张桌上

桌面是一个场，不是一条进度。

1. **主题锚点把三层拉到同一行。** 锚点是横穿三态的主题线（例如居所、身体、工作、某段关系、注意力）。至少两个时态有内容，锚点才成立（§2.3.2）。初始集合仍开放（§4.7），分镜不预定清单。
2. **单条 Node 可以先没有锚点。** 一条粗糙的现场记录本身就成立（§3.2）。Margo 事后可以提议归入某个锚点或 Scenario；观察者决定。
3. **两条时间永远同时可见：** 事件时间（事情何时发生）与档案时间（这条记录何时写下或修订）。两者的距离是信息（§2.3.3）。
4. **书写顺序自由。** 可以先写今晚，再补十年前，再放一条明年的假说。不要求章节、阶段、或「先过去、后现在、再未来」。
5. **因果不写成事实。** 观察者可以并置 A 与 B，可以写「我注意到 A 之后出现了 B」。「A 导致 B」若出现，只能是带证据等级与回访日期的假说（§2.3.4）。
6. **空白留在桌上。** 没有记录的时段标成缺口，不拿另一时态的句子填上（沉默律，§2.4 第 6 条）。

下面只是阅读用的并置示意，不是线框，也不锁定三栏版式。锚点未齐时，空着的一格是缺口（沉默律），不是待填的核心元素，也不是元素 6：

```
主题锚点：居所          状态：尚未成立（仅一态有内容）
┌ 溯源 ┐     ┌ 记录（现场）┐     ┌ 展望（假说）┐
│ 缺口  │     │ 一条现场笔录 │     │ 尚无合格假说 │
└──────┘     └────────────┘     └────────────┘
事件时间 · 档案时间 · 证据等级 · 修订史   每条 Node 自带
```

### 2.2 「不设限」停在哪里

- **生命周期不设限：** 桌上不设生命阶段关卡。童年、昨日、尚未发生的假说，都可以先成为 Node。出生前的溯源延伸多远、死亡后的终态、交接人如何指定，母文档 §4.6 仍开放。分镜允许作者写下触及两端的材料，不规定档案终态。
- **叙事边界不设限：** 指记录动作。碎片、错序、跨时态、长期空白，都可以先留下，再由 Margo 协助整理成可交接的结构。
- **不设限不改律。** 人称律、助手边界律、不干预律仍然有效。样本与观察者直接对话，本分镜不排这场（§4.8 倾向不允许，且尚未拍板）。观察者「我」的频率上限、前作「偶发跃迁」是否保留，同属 §4.8，本分镜不代决。

依据：§1.5、§2.3、§2.4 第 6 与第 10 条、§2.5、§3.2、§4.6、§4.7、§4.8；命名草案 §0「不设限项不被命名锁死」。

## 3. 档案单位与证据等级

整卷只有一个样本、一卷档案。档案内不出现其他样本或其他观察者（§2.1）。

| 单位 | 是什么 | 在写作桌上的样子 |
| --- | --- | --- |
| Dossier | 这一个样本的全生命周期上下文。没有完成态，只有当前版本（§2.5） | 整张桌子所从属的那一卷。工作标题用《Zven 卷》，标注推荐未锁 |
| Scenario | 一组可以互相解释的 Node 构成的场。不是章节，不是时间段。可横跨多年，也可以只是一个下午。Scenario 之间可以重叠（§2.5） | 桌上的一块上下文。一块 Scenario 可以同时含三态 |
| Node | 最小可记录单位 | 一次落笔。必带：时态、事件时间、档案时间、证据等级、修订史。假说态另带回访条件 |

Node 可选：所属 Scenario、主题锚点、关联 Node。一个 Node 是否可同时属于多个 Scenario，母文档倾向允许，仍待拍板（§4.7）。分镜按「可以先只属于一处，或暂时哪里都不属于」来排，不把多属写成已定规则。

相关词，只定义动作，不定义界面：

- **修订史：** 每次修订是一次新的观看。旧版可查。修订是内容（§2.3.5）。粒度待拍板（§4.7）。
- **假说回访：** 结果写成新 Node，关联原假说；原假说不改。结果三种地位平等：成立、不成立、无法判定（§2.3.6）。
- **缺口：** 被标记的空白。可以之后填上、确认为永久空白、或留待回访（§2.5）。
- **认知 × AI 时代索引：** 横切索引（注意力、人机边界、知识代谢、记忆外包等），只在某条 Node 触及时标记，不是每日必填表。维度集合待拍板（§2.5、§4.7）。

### 3.1 证据等级（示意默认）

母文档给出的示意档，分镜暂作工作默认，**档数与命名未锁**（§2.5、§4.3）：

| 示意档 | 与「发生的事」的距离 | 写作桌上的含义 |
| --- | --- | --- |
| 现场 | 最近 | 正在或刚发生。允许粗糙，解释最少 |
| 近场 | 很近的事后 | 尚未变成成型的回忆，也已不是纯粹的现场 |
| 回忆 | 事后记得 | 溯源态的常见档。可修订 |
| 转述 | 经他人或二手材料 | 只保留接触面，不升格为事实 |
| 推断 | 解释，不是事件 | 不得写成「发生过」 |

自述摘录的定级方式（按摘录时与事件时的距离，还是按自述时的状态）仍开放（§4.3）。在拍板前，摘录块照样带一个档，并允许观察者把档标成待复核；Margo 可以提议，不能改写摘录原文。

推断与事实在句子层面分开。观察者的解释不借现场档的外观（证据律，§2.4 第 2 条）。

依据：§2.1、§2.3.5、§2.3.6、§2.4 第 2 条、§2.5、§4.3、§4.7。

## 4. 写作桌节拍

一场普通的书写。顺序可以打乱；下面的编号是便于阅读的节拍，不是关卡。

### 4.1 观察者起草

主区里只有正文声。观察者用第三人称写 Zven。句子可以短，可以没有解释。现场态尤其允许粗糙（§3.2、§3.3）。

他可以写下「我在这里停留」，作为观察者的停顿，不是样本的独白。他不写命令，不写一生的定论。

若有第三人进入句子，只写与 Zven 接触的那一面，用作者指定的、相对样本的代号：寻常之人按关系（如与样本的亲属关系、同住、同事），特别的人用作者另给的特别代号。档案正文不出现真名（§4.4，第三人律）。代号本身由作者指定，本分镜不发明一套人物表。

### 4.2 Margo 边栏

边栏在正文之外开口，只对观察者。一次书写里它可以做四件事，都是提议：

1. **缺口。** 列出本段没有留下痕迹的时间或锚点。空白被命名为缺口。Margo 不拿故事把空白填上。
2. **回访。** 若存在未来态，核对三项是否齐全；到点后提醒观察者去看。回访结果由观察者书写。
3. **证据。** 质疑或提议等级。推断被写成事实时，它指出这一点。
4. **时间对齐。** 并置事件时间与档案时间；指出一条溯源其实是「此刻如何记得过去」；把可以互相解释的 Node 提议拉到同一锚点或同一 Scenario。

它称观察者为「你」，称被记录者为「样本」或「Zven」。它不对 Zven 说话，也不把生活上的「应该」说给样本。它不进入引用块，不修饰摘录的语气（§2.2.1）。

观察者采纳、改写或忽略。忽略是完整的操作。Margo 不决定记什么（§2.2.1、§2.2.4）。

### 4.3 样本自述摘录插入

观察者把样本留下的原话放进引用块。块首标明「样本自述摘录」、时间、证据等级。块内保留原始语气与原语言；双语可以并置，不强制译成正文的语言（§4.9）。

示意：

> **样本自述摘录 · 现场 · 事件时间与档案时间同日**
> 「今天先走到这里。」

摘录块内的字保持原样。观察者若另写理解，写在块外的正文里，并标成观察者的话。Margo 至多在边栏注明「摘录保留原语言」，不改引号内的字。

### 4.4 整理发生在记录之后

叙事不设限的操作含义：观察者可以先把一段话丢在桌上——错序、只有半句、三态只写了一态。Margo 随后协助把它收成可交接的结构：时态、两轴时间、证据、缺口、是否够格进入未来层、可归入哪条锚点。

不合格的未来句（缺回访时间点或缺「怎样算不成立」）不作为未来态 Node 写入（§2.3.1）。观察者可以继续写别的时态，或等三项齐全后再把这句话写入未来层。这里不另设一种叫「草稿」的档案单位。

依据：§1.2、§2.2、§2.3、§2.4、§3.2、§3.3、§4.4、§4.9。

## 5. 情感反差节拍

科幻壳是距离与许可，情感核是重量。反差的律法：语言越克制，被记录之物越重（§1.4）。引力只以结构出现（§1.6）。

| 节拍 | 桌上发生的事 | 重量从哪里来 |
| --- | --- | --- |
| 壳 | 正文用观察站的语法，短，少形容词。「Zven 在这一日离开工位的时间早于往常。」 | 距离让这句话能被写下，也能被日后读下去 |
| 停留 | 观察者在某一 Node 停得更久，正文不解释原因 | 情感通过选择流露，不通过抒情（§1.4） |
| 弱区 | 一段时期方向不明，标成「引力弱区」 | 不填补、不美化、不回避。弱区是上下文（§1.6） |
| 沉默 | 几个月没有新 Node。桌上是一个被标记的缺口 | 不记录也是记录（沉默律）。Margo 不催促补写 |
| 回访落空 | 一条旧假说到点。观察者写下「不成立」，作为新 Node。原假说保持原样 | 不成立比成立更让时间显出重量（§2.3.6、§3.1） |
| 边栏不升温 | 同一时刻 Margo 只问：缺口在哪、证据是哪一档、事件时间与档案时间差多少 | 它没有安慰任务。安慰会把这层反差抹平 |

不排这些场：给样本的鼓励、人生意义的答案页、「你已经很不容易」式的边注、为了作品密度而制造的生活事件（§1.6、§3.3、反鸡汤律）。

观察站的限制本身是情感的入口：不能改变样本，不能读取没有痕迹的内心，观看有盲区，观察者与样本在同一条时间里老去（§1.4、§2.1）。全知的旁白不在这套分镜里。

依据：§1.4、§1.6、§2.1、§2.3.6、§2.4 第 6 与第 10 条、§3.1、§3.3。

## 6. 发布与私密

公开程度是分层的，默认从最保守开始（§3.3、§4.5）。

节拍：

1. **新 Node 默认不对外。** 写完只是进入当前版本的档案，不是发布。
2. **可见性写在 Node 上。** 作者按条选择公开什么。Scenario 可以另有一层选择；未单独设定的条目保持保守默认。两层如何互相覆盖，留给线框，本分镜不另造规则。
3. **发布不是定论。** 公开出去的仍是当前版本里的材料。读者的反应不构成修订理由（§3.3）。
4. **抹除留痕。** 仅两种情形可以抹除：第三人隐私，或样本明确撤回。留下「此处曾有一条记录被撤回」（修订律，§2.4 第 3 条）。
5. **双语的公开条目可以含未翻译的摘录。** 原语言是材料的一部分（§4.9）。

本分镜不排、也不预做决定的两场（仍开放）：

- 是否另有「仅交接人可见」层（§4.5）。
- 第三人能否对自己相关的 Node 提出撤回请求（§4.4）。

依据：§2.4 第 3 条、§3.3、§4.4、§4.5、§4.9。

## 7. 第一次 Scenario／Node 路径

第一次坐下时，桌子是空的。空是缺口，不是失败，也不是引导教程。没有第六槽，没有观察者的名字，没有对样本的欢迎词。

工作页眉可以是推荐未锁的《Zven 卷》与那句定位语，并标明未锁。

### 7.1 节拍

1. **一条现场。** 观察者写下当晚能留下的最小现场，第三人称，可以没有主题。示意：「Zven 在这一日离开工位的时间早于往常。原因未记。」事件时间与档案时间都落上。证据档暂用示意默认里的「现场」。
2. **可有可无的摘录。** 若当时有一句原话，放进「样本自述摘录」块，带时间与证据档。没有原话就不造一句。
3. **第三人只以代号进入。** 若句子必须提到别人，用相对 Zven 的关系代号。不写真名。不推测对方的内心。
4. **Margo 在边栏开口。** 示意：
   > 这条 Node 尚未归入 Scenario。事件时间与档案时间同日，与「现场」档一致。正文没有解释「早于往常」的参照是哪一段时期——若你要留，它是缺口，不是推断。尚无未来态。
5. **观察者决定要不要一块 Scenario。** 他可以把这一条单独留着，也可以命名一块很小的场（一个下午也够，§2.5）。名称由他写。Margo 不代取人生阶段的名字。
6. **第二态可有可无。** 若他愿意，再写一条溯源（「现在如何记得过去」）或一条合格假说。两态齐了，某个主题锚点才成立。只有一态时，锚点行显示为尚未成立，空格保持为缺口。
7. **假说若要写，当场核对三项。** 缺回访时间点或然否条件时，Margo 告诉观察者它还不能作为未来态写入。观察者补全，或先不写。
8. **默认不发布。** 这条 Node 的可见性停在最保守。作者以后再选。

### 7.2 这次结束时桌上有什么

- 至少一条带两轴时间与证据等级的 Node。
- 零或一条摘录，零或数个代号，零或一个尚未成立的锚点。
- 边栏里一份缺口与对齐说明，正文不依赖它也能读。
- 没有对 Zven 的建议，没有意义结论，没有第六格，没有已锁定的站名或观察者专名。

以后的会话重复这个循环：记录可以很随便，整理交给 Margo，决定权留在观察者。回访日到来时，另开一条结果 Node，不改旧假说。

依据：§2.2、§2.3、§2.5、§3.2、§4.1、§4.2、§4.3、§4.4、§4.5。

## 8. 留给日后线框的开放注记

本节只列线框必须守住的边界，以及母文档已经给到概念层、却尚未设计的东西。不在这里发明与母文档相冲突的功能。

### 8.1 线框要守住的

- 三种声音分居三处：主区、主区内的摘录块、可折叠边栏。没有第四个说话区，没有「对 Zven 说」的输入（§2.2.2）。
- 边栏折上之后，正文仍是完整作品（§3.1）。
- 桌面上是三态并置的可能，不是六个核心槽。元素 6 不占位（§4.1）。
- 新记录默认不可见；可见性至少能落在 Node 上，Scenario 级为可选（§4.5）。
- 摘录可保留原语言（§4.9）。
- 页眉标题、样本称呼、定位语以推荐未锁呈现，直到作者另锁（§4.2）。
- 观察者在界面里的称呼是「观察者」。不使用未选用的观察方专名。助手称呼是 Margo·玛戈。
- 观察站是位置，不是一段必须被画出来的文明史。物理形态刻意留空（§2.1）。站名仍开放，线框用通名「观察站」即可。

### 8.2 母文档已有、线框尚未展开的概念

这些是载体含义，不是本分镜新增的功能（§3.4）：

- 每个 Node 有持久地址，便于引用与交接。
- 持久优先于催促。没有推送、没有打卡、没有连续签到。档案不催样本，与不干预律一致。
- 三栏并置在网页上比在竖屏上更自然；是否做成字面三栏，由线框决定，分镜只要求三态能在同一桌面上被一起看见。
- 公开与私密可以在地址层面分开。机制未定。

### 8.3 线框不要补上的

- 面向样本的诊断、目标、优化建议、情绪打分卡。前作的这类逻辑在新作里被反转（附录、不干预律）。
- 每日必填的追踪表。相关维度只在触及时进入锚点或时代索引（§2.5、附录）。
- 把推断画成与现场同等的事实样式。
- 用空槽表示「待填的第六元素」。
- 样本编号 001，或其他暗示还有别的样本的序列（§2.1、附录）。
- 观察者与样本的对谈场、Margo 进入正文的角色场。
- 为「仅交接人可见」或「第三人撤回请求」预做已定界面。二者仍开放（§4.4、§4.5）。

### 8.4 仍开放、分镜不代决

便于线框作者不要把空隙填死：

| 母文档 | 仍开放的内容 |
| --- | --- |
| §4.2 | 观察站专名；「Zven」与作者实名的公开程度。标题、样本称呼、定位语为推荐未锁 |
| §4.3 | 证据档数、命名、摘录如何定级 |
| §4.4 | 第三人能否请求撤回相关 Node |
| §4.5 | 是否存在「仅交接人可见」 |
| §4.6 | 溯源是否及如何延伸到出生前；死亡后的终态；交接人机制与权限 |
| §4.7 | 主题锚点初始集合；修订粒度；时代索引的维度；Node 可否多属 Scenario |
| §4.8 | 样本与观察者能否直接对话；观察者「我」的频率；前作语气遗产 |

依据：§2.1、§2.2、§2.5、§3.4、§4、附录。
