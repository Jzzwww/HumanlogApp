# 写作桌用法

> 给 Human。你既是样本 Zven，也是观察者。这一页只讲怎么坐下写。
> 样本页 `docs/samples/zven-sample-scenario-node-001.md` 是格式演示，不是本手册。要看一条 Node 长什么样，去那一页；要知道今晚先做什么，留在这里。
> 上游：母文档 v0.1.2、分镜 v0.1.1。观察者无专名。标题、样本称呼、定位语仍是**推荐未锁**。本页不设第六项。

---

## 1. 一个人，两条入口

下笔前先问一句：

> **要留档还是要被听懂？**

同一个人，两条轨道。先选这一次的需要，再动笔。

### 观察者轨 — 要留档

- 你以观察者执笔。写 Zven 用**第三人称**。
- 助手是 **Margo · 玛戈**。它只辅佐观察者：缺口、证据、回访、时间对齐。
- 它不对样本说话，不安慰，不给生活建议，不说「你应该」。
- 这个称呼已经锁定。Zven 轨的助手不替换它。
- 这一轨的成品可以进入档案：正文，加上可折叠的侧栏。

### Zven 轨 — 要被听懂

- 你以 Zven 写。用**第一人称**。
- 旁边是**另一位**助手。它充分理解你，并陪伴你把话说完。它不是 Margo。
- 暂名：**「陪写」** / *Companion-desk*。**暂名未锁。** 你可以改名。改名之前，就用这个暂名。
- 陪写的话留在 Zven 层或私聊。不写入观察者正文，也不冒充 Margo 的边栏。

留档要的是日后还能读懂的上下文。被听懂要的是当下有人跟得上。两件事可以先后做，不必在同一段里假装已经是档案正文。

---

## 2. 过程可以混，落盘要收回格式

写的时候，角色可以模糊，两轨可以来回。你可以从第一人称起笔，中途改成第三人称；也可以先跟陪写说完，再决定要不要留档。这不算违规。

**落入档案时，格式收回来。** 下面四条是硬的：

1. **观察者正文用第三人称写 Zven。** 观察者的「我」可以少少出现，只标记停留或不确定，不替样本总结一生。
2. **样本的第一人称只出现在「样本自述摘录」里。** 块上标明时间、证据等级，以及「样本自述摘录」。块外立刻回到第三人称。摘录保留原话，不修饰。
3. **Margo 不在正文里对 Zven 说话。** 它只在侧栏，只对观察者。侧栏折上之后，正文仍然完整。
4. **陪写的笔记留在 Zven 层或私聊。** 不贴进观察者正文，不写成边注。若要把某一句原话留档，放进摘录，不把整段对话搬进去。

过程里的混乱留在桌上。档案里的句子要能被一个还不认识你的人读懂。

## 3. 记什么，不记什么

### 记

- [ ] 让这一刻可被理解的最小上下文：当时为何这样决定、这段关系的实际温度、这件事的体积。不必是成就。
- [ ] 现场可以粗糙。正在或刚发生的，先留下。解释可以后补，现场不能。
- [ ] 两条时间一起写下：事情何时发生（事件时间），这条记录何时写下（档案时间）。
- [ ] 过去写成「现在如何记得过去」，不写成已经核实的日程。
- [ ] 未来写成假说，三项齐：假说内容、回访时间点、怎样算不成立。
- [ ] 没有留下的空白，标成缺口。空白本身可以记。
- [ ] 要保留的原话，放进「样本自述摘录」。原语言可以留着。
- [ ] 提到别人时，只写与 Zven 接触的那一面，用代号（下一节）。
- [ ] 证据等级先用示意档即可：现场／近场／回忆／转述／推断。档名仍未锁。推断不要借现场的外观。

### 不记

- [ ] 真名。
- [ ] 对样本的命令、建议、「应该」、打气、鸡汤。
- [ ] 人生意义的结论句。档案不回答「这一生是什么」。
- [ ] 把愿望写成未来。缺回访点、或缺「怎样算不成立」的句子，不作为未来态写入。
- [ ] 把推断写成已经发生的事。
- [ ] 推测第三人的内心，或替对方说话。
- [ ] 为了让档案看起来密，而特意制造生活事件。几个月不写，只是一个缺口。
- [ ] 陪写的安慰、追问、复述。这些留在 Zven 层或私聊。
- [ ] 第六项核心元素。该项已取消，不要另造一格来填。

不确定就少写。一条短的现场，好过一段事后补圆的故事。

---

## 4. 第三人代号

正文里的其他人，用你指定的、**相对样本 Zven** 的代号。不写真名。

- 寻常的人：按与样本的关系起代号（亲属、同住、同事）。一人一个，或一类一个，由你定。
- 特别的人：另给特别代号。
- 只写接触面：对方做了什么、说了什么与 Zven 相关的那一层。不写对方心里怎么想。
- 代号表由你维护。本手册不预造人物表。样本页里的「同事甲」「友人·烛」只是占位，不是正式代号。

---

## 5. 分级发布；可以双语

- 新写下的 Node **默认不对外**。写完是进入档案的当前版本，不是发布。
- 可见性写在 **Node** 上。公开哪一条，由你选。Scenario 可以另设一档；没设就保持保守。
- 公开出去的仍是当前版本，不是定论。别人的反应不是修订的理由。
- **双语可以。** 正文与摘录不必同一语言。摘录保留原语言。不必为了整齐而把原话翻译掉。
- 抹掉一条，只在两种情形：第三人隐私，或你（作为样本）明确撤回。留下「此处曾有一条记录被撤回」。

---

## 6. 一场怎么走

1. **选轨。** 问「要留档还是要被听懂？」留档走观察者轨；被听懂走 Zven 轨。也可以先走一条，再换。
2. **写。** 观察者轨：第三人称，短句也可以。Zven 轨：第一人称，让陪写跟得上。过程中角色混在一起，先写完。
3. **可选：把 Zven 笔记提升为观察者 Node。** 不提升的笔记留在 Zven 层或私聊，这场也可以到此结束。提升时：正文改成第三人称；要留的原话放进「样本自述摘录」；陪写的话不跟进去。补上时态、事件时间、档案时间、证据等级。
4. **Margo 整理。** 只在观察者一侧、只对观察者：缺口、证据等级、两条时间是否对齐、回访三项是否齐全、可否归入某条锚点或某块 Scenario。你采纳、改写或忽略。忽略是完整的操作。它不决定记什么。

没有必须每天写。

---

## 7. 样本页不是这本手册

`docs/samples/zven-sample-scenario-node-001.md` 演示一块 Scenario、一条 Node、三种声音怎么分开。用它对照格式：正文、摘录块、侧栏各在何处。

不要用它当操作说明，也不要把它当成已经发生的档案。那一页里的语气、占位代号、示例日期，都停在那一页。

沿用、不在本页改掉的：观察者仍然没有专名；标题、样本称呼、定位语仍然是推荐未锁；不设第六项。

若这里和母文档冲突，改这里。
