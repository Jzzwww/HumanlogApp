# Zven 作品视觉基调提案

**2026-10-18 · Nevs 提案 · 等待 Zven 定调。** 本轮只研究风格与约束，不实施网页，也不将先前方案或本页建议记为设计认可。以下方向名称用于讨论，不是站点名称。

## 1. 风格定义

建议总称为 **黑白心理超现实**，以「巨构、身体与失重的仪式性影像」说明它的具体组成。

这组图的力量来自身体处境：人被建筑压小，被光隔开，又被放大到占满空间。空间可以辨认，却不能完全解释；观看者能感到重量、距离和不安。科幻感主要由这种空间关系产生，信息和装饰都很克制。

因此，新方向的目标是让人进入一个有独特气质的观看现场，再逐步读到 Zven 的档案。它仍需要支持清楚、持久的阅读。视觉上的神秘不能变成找不到内容，心理压力也不必贯穿每一页。

## 2. 五张附件分别提供什么证据

- **IMG_4592**：狭长亮口位于中轴，细小人形处在明暗交界；两侧大块暗部和下方的影像延伸压缩入口。可借鉴的是「极少的光定义方向」与人、巨构之间的尺度悬殊。
- **IMG_4590**：人物侧面轮廓覆盖明亮矩形，近处暗边形成另一重框。可借鉴的是身体作为空间的遮挡，以及近乎平面的轮廓和纵深之间的张力。
- **IMG_4589**：不同大小、不同朝向的躯体围绕光雾分布，缺乏稳定地面参照。可确认的是悬置感；单帧不能判断它们正在下坠、上升还是停留。
- **IMG_4591**：巨墙、斜阶、三角光口与极小人物构成尺度冲突，墙面和岩体保留粗粝质地。它适合成为建筑主导方向的锚点：形体少，空间关系强。
- **IMG_4588**：面孔及其周围的多只手占据中心，暗部吞没外围，身体变成心理压力的主要载体。它适合局部章节，但侵入感比前四张更强。

五图都能观察到单色层次、软边、颗粒及局部晕光。**截图无法确定这些效果在原片中的准确强度与制作方法**：压缩、截图和原素材可能共同造成当前观感，也不能据此认定原片的剪辑节奏、镜头运动或声音设计。

## 3. 可执行的视觉约束草案

以下是从图片推导的设计建议，等待选择；涉及数量、时长或其他参数时，均是试稿起点，不是从静帧测得的事实。

**构图与光。** 一个主要画面围绕一个空间事件展开，例如一道光口、一面巨墙或一具悬置身体。允许中心轴、斜切、遮挡与明显尺度差；光源承担引导，尽量避免到处同时发亮。首屏可只保留作品名、一句引导与主要入口，详细索引在进入后展开。

**色与材质。** 先以黑、炭灰、雾灰、近白建立层次，保留中间调。粗糙墙面、光雾、影像颗粒可用于场景，避免每个界面零件都添加纹理。彩色强调尚待决定，不因游戏联想直接引入红色。透明玻璃卡片、荧光描边和线框球体不作为这轮的默认语言。

**字体。** 参考图中的文字克制地退在画面边缘，可借鉴其紧凑、清楚的无衬线排法。中文优先保证字形和行距稳定；标题可以有明显尺度，正文与辅助信息拉开层级。不要把英文字幕的宽字距机械套到中文，也不要靠大量小标签制造精密感。

**动效。** 首轮可尝试缓慢的光域变化、小幅尺度变化、短暂复像及场景之间的淡入或切换。建议先让一次场景过渡落在约 600–1000 毫秒，再看它是否拖慢阅读；这一数值只供后续试验。正文、输入与主要操作保持稳定；减少动态效果时仍能完整使用。持续晃动、强闪烁和所有对象同时漂浮，都不应成为气氛的依赖。

**阅读。** 图像场负责进入作品，阅读面负责承接内容。长文出现后应有稳定底色和明确文字对比，颗粒、失焦、复像不能覆盖正文。用户可以直接打开一条记录，无需每次经过片头；返回索引和切换读法保持可辨认。

**信息架构。** 六维继续组织内容，双轨仍是可选书写姿势，不画成左右两座主世界。维度入口可以分阶段出现，但不能因构图而丢失查找能力。正文、摘录、Margo 边注的既有关系不变；光、门与身体只是视觉手法，不新增世界观能力、档案单位、可见性或命名政策。

## 4. 交给 Zven 选择的两种重心

**A · 建筑主导：冷峻、疏离、尺度。** 以 IMG_4591、4592 为锚。巨构、空洞和光承接日常浏览，人物少量出现，读者保持一定观看距离。它更容易让长期档案和沉浸感共存；风险是过度抽象后，留下漂亮但缺少人的空间。

**B · 身体主导：亲密、不安、心理压力。** 以 IMG_4590、4588 为锚，IMG_4589 连接身体与空间。轮廓、姿态、遮挡及复像成为章节的主要形象。它更直接地触及个人记录，也更有冲击力；风险是让作品持续带有惊悚意味，或让具象人物抢先替 Zven 定义身份。

**Nevs 建议：A 作为常态，身体在少数章节局部出现。** 这样可以保留巨构的观看距离，并在需要时让个人处境显影。此建议未获批准；最终应由 Zven 决定建筑与身体的比重，以及可以接受的不安程度。若 Zven 希望每次进入都先感到身体与心理的冲击，B 应成为主方向。

## 5. 三组相邻参考

**NaissanceE：建筑与光的参照。** 开发者的 Steam 页面将巨大未知空间中的孤独、迷失和探索列为核心体验。可用它检查 A 是否能仅靠尺度、结构与明暗成立，不必借入游戏的闯关机制。[官方商店页](https://store.steampowered.com/app/265690/NaissanceE/)

**INSIDE：身体与环境关系的参照。** Playdead 官方页提供预告与截图，可对照研究人物怎样在有限画面中保持可辨认、环境怎样承接压力。这里是后续观看的比较问题，不将它的剧情或游戏机制搬进作品。[官方作品页](https://playdead.com/games/inside/)

**Control（2019）片头：影像材质的参照。** Duncan Elms 的作品页与 Materia 的制作页提供同一项目的材料；Materia 明列其模拟纹理参与。可沿此研究有物质感的抽象影像。[Duncan Elms](https://www.duncanelms.com/control-main-title/) · [Materia](https://www.materia.tv/control-2019)

2019 年项目不等于用户本次所称的《控制共振／Control Resonant》来源；本轮未完成五张附件与原片、制作方的逐帧核实，不能把上述署名转移给这组截图。所有参考图仅供风格研究，不直接作为生产资产；游戏人物也不能代替 Zven。定调后再制作属于此作品的形象。
